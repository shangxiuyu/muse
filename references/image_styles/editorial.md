# 杂志编辑信息图

<!-- muse:genre spec -->

标识：`editorial`。检索别名：杂志信息图、editorial、editorial-infographic。

## 视觉特征

- 用标题、导语、主图、标签与注释建立字级；核心判断在视觉上先于解释细节。
- 围绕信息关系组织图解、局部放大与重点标注；内容可形成流程、对比或剖解，各区分量随信息重要性变化。
- 色彩承担类别与重点编码，细分隔线和对齐帮助阅读；来源与限定随对应内容放置。

## 可调参数

标题力度、栏数、留白、图文比例、强调色、注释密度。可采用冷静专业或鲜明编辑语气，排版随画幅推导。

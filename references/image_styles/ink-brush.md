# 水墨写意

<!-- muse:genre spec -->

标识：`ink-brush`。检索别名：水墨、墨笔、ink-brush。

## 视觉特征

- 用有提按、顿挫和收锋的笔势塑造主体，干笔纹理与湿墨晕染形成层次。
- 浓墨承担焦点与力量，淡墨和留白建立空间；景物与动作跟随内容，而非由风格自动补齐。
- 少量点色可以承载情绪或品牌识别，文字与主体之间留出清楚的关系。

## 可调参数

写意程度、笔势力度、墨色浓淡、干湿比例、留白位置、点色面积。主体可以是现代物件、人物或抽象关系。

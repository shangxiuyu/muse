# 手绘知识图

<!-- muse:genre spec -->

标识：`sketch-notes`。检索别名：手绘图解、马卡龙知识图、sketch-notes。

## 视觉特征

- 用略有起伏的墨线把标题、对象与连接串成同一种手绘语言；线条的自然变化保留在轮廓上，文字仍清楚。
- 用浅色区块区分信息职责，图标承担解释作用。每块围绕一个要点，箭头表达明确的先后、因果或归属。
- 在主体之间留出阅读间隔；强调线与小涂鸦跟随重点，标题、主体与结论的比例由内容决定。

## 可调参数

墨线粗细、分区形状、图标详略、手写程度、信息密度。可从奶油纸与马卡龙色起步，也可换成纯白底、冷色或品牌配色。

## 提示词片段

以下片段加入当前任务的内容、构图、准确文字与规格之后，依用户要求调整：

> 以手绘知识图呈现已给定的内容：略有自然起伏的墨线，易读的手写标题与短句，解释含义的小图标，浅色区域标识不同信息职责。按内容关系安排区块和箭头，让读者顺着连接读懂结论。使用本次指定配色，手绘纹理轻于文字。

## 验收观察

先看区块、图标和连接能否共同解释内容；再看手绘笔触是否贯穿全图，中文与箭头端点是否清楚。更换配色后仍应认得出手绘图解。

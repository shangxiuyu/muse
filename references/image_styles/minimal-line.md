# 极简线稿

<!-- muse:genre spec -->

标识：`minimal-line`。检索别名：Notion 类线稿、notion、minimal-line。

## 视觉特征

- 把主体压缩成少量可辨识的轮廓、姿态和物件，选一个动作或对象关系承载主要意思。
- 用留白隔开主体与解释；保留轻微手绘感，以单一线条体系形成安静、清楚的视觉节奏。
- 强调色只标记关键对象、连接或状态。需要文字时采用短标签，让图像仍能独立传达主要关系。

## 可调参数

轮廓粗细、手绘起伏、人物抽象程度、留白位置、强调色面积。底色与墨色可随品牌改变。

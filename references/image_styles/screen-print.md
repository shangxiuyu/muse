# 丝网版画海报

<!-- muse:genre spec -->

标识：`screen-print`。检索别名：丝网印刷、版画海报、screen-print。

## 视觉特征

- 选一个能承载主张的剪影或象征关系，利用正负形和色面交界形成视觉焦点。
- 用少量分色层建立冲击力，纸纹、半调网点与轻微套印偏移呈现印刷触感。
- 标题与图形共同组织画面，字形的重量和位置回应主体剪影，而非另贴一块文字。

## 可调参数

分色数量、明暗底、剪影详略、网点密度、套印偏移、标题尺度。可从双色或少量对比色起步，具体色数按内容和品牌调整。

# 水彩插画

<!-- muse:genre spec -->

标识：`watercolor`。检索别名：水彩、水彩手绘、watercolor。

## 视觉特征

- 用透明色层、局部积色与水迹边缘形成手绘质感；主角轮廓在柔软边缘中仍有辨识点。
- 以色层深浅和边缘清晰度区分焦点与环境，留白可参与表现空气、光或情绪。
- 物件与人物采用概括而有动作的形体，纸纹与笔触的尺度随画幅协调。

## 可调参数

冷暖、饱和度、干湿笔比例、晕染范围、纸纹颗粒、写意程度。可从温柔浅色起步，也可采用冷色、浓色或单色水彩。

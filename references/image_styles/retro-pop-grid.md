# 复古波普

<!-- muse:genre spec -->

标识：`retro-pop-grid`。检索别名：波普网格、复古波普、retro-pop-grid。

## 视觉特征

- 用有重量的轮廓、分隔与标题建立强烈图形感，平涂色块承担区域和信息的区分。
- 黑白反转、棋盘格或点线纹样形成节奏，重复图形与稀疏区域交替，让重点跳出。
- 网格分区可随内容调整大小和跨度，图标与文字保持清楚对齐；色彩和轮廓共同形成复古印刷感。

## 可调参数

分区数量与跨度、轮廓粗细、复古柔色或高饱和色、黑白面积、纹样密度、标题尺度。

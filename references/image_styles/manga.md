# 叙事漫画

<!-- muse:genre spec -->

标识：`manga`。检索别名：漫画、日漫画风、manga。

## 视觉特征

- 以角色表情、视线、动作和物件关系推动叙事，线条轻重帮助读者抓住情绪。
- 用景别变化和留白安排节奏；分镜、气泡与文字阅读方向共同构成清楚的先后顺序。
- 网点、速度线与情绪符号按当前动作选用；重复角色通过稳定外貌、服装和比例保持识别。

## 可调参数

黑白或彩色、角色比例、线条力度、网点密度、分镜数量、情绪夸张程度。分镜数与故事长度由任务决定。

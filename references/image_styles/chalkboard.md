# 黑板粉笔

<!-- muse:genre spec -->

标识：`chalkboard`。检索别名：黑板图解、粉笔画、chalkboard。

## 视觉特征

- 让文字、轮廓与箭头呈现相同的粉笔颗粒和断续边缘，板面保留轻微擦拭层。
- 用亮色笔迹建立主次，关键步骤通过圈画、下划线或简图推进。
- 保留自然书写节奏和分区间隔，板面痕迹弱于当前讲解内容。

## 可调参数

黑板或深绿板面、粉笔粗细、颗粒量、重点色、字迹起伏、板框显隐。可调整板色与粉笔色形成不同课堂气质。

# 视觉母体：Native Serene Productivity（原生极简静室与呼吸清单流）

> **标杆来源**：`Things 3` (Cultured Code), `Bear` (Shiny Frog), `Apple Notes`  
> **核心隐喻**：纯白静室纸张 (Serene White Canvas) + 极度克制的单重点蓝 (`#4F97FF`) + 暖阳 Today 金星 (`#FFD60A`) + 浮动精准定位 Magic-Plus + 圆圈弹簧勾选 (Circular Spring Check) + 纯净 Inset Grouped 内嵌留白。

---

## 1. 业务场景匹配指南 (Scenario & Domain Affinity)

### 🎯 天然最佳业务场景 (Natural Fit)
* **个人 GTD 待办与极简日程管理 (To-Do & Tasks)**：无压力、无弹窗轰炸、以“清空今天（Clear Today）”为核心目标的任务工具。
* **高私密性极简日记与随手笔记 (Micro-Journaling & Notes)**：排版干净如晨间白纸，消除记录焦虑。
* **个人健康打卡与习惯追踪 (Habit Tracking)**：纯粹的圆圈勾选微反馈，形成自律的多巴胺回路。
* **极简购物清单与行李打包助手 (Checklists & Pack Lists)**：单手拇指快速勾销，清晰明了。

### 🚀 降维打击 / 跨界创新场景 (Breakthrough Cross-overs)
* **极简医疗随访与术后恢复清单 (Post-op Recovery Flow)**：打破传统病历软件冷冰冰且充满焦虑的表格界面，用白纸般的呼吸感引导患者每天完成“服药、测温、慢走”，大幅降低就医心理压力。
* **独立法务/顾问服务工时精简签派**：告别纷繁复杂的工单系统，让高净值独立顾问在手机上一目了然查看今日关键客户里程碑。
* **高阶极简电商订单发货核验 (Artisan Packing)**：手作人、高定品牌打包时，每装入一件单品轻点圆圈打勾，充满仪式感。

### 🚫 严格禁止场景 (Anti-Patterns / When NOT to use)
* **重度协同且高频讨论的敏捷看板 (Agile Scrum Board)**：需要密集展示跨部门头像、评论气泡、多级状态泳道，静室流的克制会因信息过密而坍塌。
* **高频交易与瞬态行情监控 (Day Trading / Crypto Charts)**：需要高饱和红绿涨跌跳字与多重分时指标，与本风格的禅意纯白相悖。
* **强社交互动与瀑布流推荐 (Social Feed)**：本风格追求“做完即离开”，绝不设计留存诱导机制。

## 2. 母体之魂与核心基因 (Soul & Core Ethos)

> 💡 **母体之魂**：**数字世界的禅修静室——在信息过载与赶工焦虑中，让人的注意力回归当下呼吸的轻盈与从容**。大部分生产力软件像一台冷酷催促的监工机器；本母体将界面彻底净化为一张清晨未拆封的空白棉纸。通过极度克制的单色重点蓝（`#4F97FF`）、金星徽章（`#FFD60A`）、Magic-Plus 磁吸插入手势与弹簧微震感圆圈打勾，让每一次任务完成都变成一次内心的清空与释放。

* **禅意白纸（The White Room Paradigm）**：纯白（`#FFFFFF`）与柔灰（`#F5F6F8`），去掉所有臃肿死沉的顶栏与标签栏。
* **单色双子星纪律**：全站仅允许冷重点 Things Blue 与暖重点 Today Yellow，其余层级全靠墨水灰阶优雅拉开。
* **Magic-Plus 磁吸自由定位手势**：右下角拇指核心热区，长按拖拽至任意行间精准松手插入。
* **圆圈弹簧多巴胺勾选（Circular Spring Check）**：由内向外绽放柔蓝并伴随触觉微弹跳，抚平烦躁。

## 3. 三大排版拓扑发散矩阵 (Three Layout Paradigms & Mutations)

> ⚡ **AI 消费指引 (学魂变骨)**：静室清单绝非只有单调流水账！根据具体移动任务场景选择或组合以下骨架：

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                      Native Serene Productivity 三大拓扑发散矩阵                                │
├────────────────────────────────┬────────────────────────────────┬──────────────────────────────┤
│ 范式 A：静室垂直层级流 (Things)│ 范式 B：分段呼吸时间轴 (Rhythm)│ 范式 C：闪念抽屉流 (Sheet)    │
├────────────────────────────────┼────────────────────────────────┼──────────────────────────────┤
│ 适用：个人 GTD、大纲清单、待办 │ 适用：每日晨午暮规划、服药打卡 │ 适用：碎片灵感捕捉、快速记事  │
└────────────────────────────────┴────────────────────────────────┴──────────────────────────────┘
```

### 范式 A：【经典层级】Things 3 式静室垂直层级流 (Hierarchical Task Stream)
* **设计意图**：以大写前缀（Kicker）内嵌分组，支持按大纲/项目收拢展开，Magic-Plus 随时随地插入。
* **适用场景**：个人每日 GTD、多阶段筹备清单、极简旅行行李清单。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌────────────────────────────────────────┐
  │ [今日 Today · 金星徽章 ★ · Newsreader 34px] │
  ├────────────────────────────────────────┤
  │ ┌────────────────────────────────────┐ │
  │ │ MORNING FOCUS · 清晨专注 (Kicker)  │ │
  │ │ ◯ 审阅 Q3 团队设计母体方案         │ │
  │ │ ◯ 给阳台薄荷草浇水                 │ │
  │ └────────────────────────────────────┘ │
  │ ┌────────────────────────────────────┐ │
  │ │ AFTERNOON · 午后事务               │ │
  │ │ ◯ 14:00 客户设计交付评审 (带标签) │ │
  │ └────────────────────────────────────┘ │
  │                                   [+]  │ ◄── 磁吸 Magic-Plus 悬浮纽
  └────────────────────────────────────────┘
  ```

### 范式 B：【呼吸节奏】分段呼吸时间轴 (Segmented Day Rhythm)
* **设计意图**：将一整天划分为晨曦、正午、黄昏三段可折叠呼吸卡片，避免一眼看到 20 件事的窒息感。
* **适用场景**：习惯打卡、术后服药康复计划、间歇性专注训练。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌────────────────────────────────────────┐
  │ [ 晨间阶段 08:00 - 12:00 · 2/3 完成 ]  │ ◄── 顶部细线圆环进度
  │ ┌────────────────────────────────────┐ │
  │ │ ✔ 晨跑 3km 与温水补给              │ │
  │ │ ◯ 服用复合维生素片                 │ │
  │ └────────────────────────────────────┘ │
  │                                        │
  │ [ 午后静候 13:00 - 18:00 · 折叠收拢 ▾] │ ◄── 尚未开始的阶段静候折叠
  │ [ 晚间安歇 19:00 - 22:00 · 折叠收拢 ▾] │
  └────────────────────────────────────────┘
  ```

### 范式 C：【极速捕捉】灵感闪念与待办抽屉流 (Quick Inbox & Floating Sheet)
* **设计意图**：首屏纯净居中，单手大拇指从屏幕顶部下滑快速捕获，底部多段吸附抽屉（Bottom Sheet）随叫随到。
* **适用场景**：会议随手记、即时灵感捕获箱（Inbox）、即时结账清单。
* **拓扑骨架**：全屏极简空白纸底，呼出时半屏抽屉自底向上弹性吸附（支持 30%、60%、全屏三挡吸附）。

## 6. 字体与移动端排印规范 (Typography Tokens)

* **推荐字体**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "Inter", sans-serif`
* **移动端排印尺度**：
  * **一级大标题 (Large Title)**：`28pt / 34px`，Weight 700，字距 `-0.02em`（如列表顶部的 "今天"、"收件箱"）
  * **分组标题 (Headline)**：`17pt / 22px`，Weight 600，字距 `-0.01em`
  * **清单正文 (Body)**：`16pt / 21px`，Weight 400 ~ 500
  * **辅助说明与日期 (Footnote)**：`13pt / 18px`，Weight 400，颜色固定为 `var(--text-secondary)`
  * **大写前缀 (Kicker / Section Label)**：`11pt`，Weight 700，字距 `0.1em`，全大写

## 7. 微交互与触觉规约 (Motion & Haptics)

1. **触觉震动映射 (Haptic Pairing)**：
   * **打勾完成**：触发轻微中度震动（`UIImpactFeedbackGenerator(style: .medium)` 或振动时长 `15ms`），给用户切实的“完成一件事情”的物理爽感。
   * **长按拖拽 Magic-Plus**：触发轻微重度震动（`UIImpactFeedbackGenerator(style: .heavy)`），暗示脱离锚点已激活。
2. **阻尼物理曲线 (Spring Physics)**：
   * 列表展开与卡片收起统一使用弹性贝塞尔：`cubic-bezier(0.25, 1, 0.5, 1)`，耗时 `240ms`。
   * 严禁生硬线性的线性动画（Linear Animation）。

## 8. 核心反模式红线 (Forbidden Patterns)

* 🚫 **严禁常驻沉重的底部 TabBar 与花哨顶栏**：静室流的灵魂在于将屏幕完全归还给用户内容，绝不让冗余常驻导航栏挤压视线。
* 🚫 **严禁破坏单色双子星纪律**：严禁随意引入紫色、橙色、粉色等杂乱色彩，除 Today 金星与 Things 蓝外，全站必须遵守墨水灰阶规范。
* 🚫 **严禁生硬方角复选框**：任务打勾必须是 `20px` 细线空心圆圈，严禁使用浏览器原生方块或尖角 checkbox。
* 🚫 **严禁单一清单模板套用**：AI 必须根据移动业务形态在垂直层级流、分段呼吸时间轴与闪念吸附抽屉间自由选骨，切勿生搬硬套！

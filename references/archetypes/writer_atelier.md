# 视觉母体：Writer's Atelier（作家案头与卡片工坊流）

> **标杆来源**：现代沉浸式写作工作台（如 `Lex`, `Craft`, `iA Writer`, `Bear`）  
> **核心隐喻**：暖燕麦棉纸底色 + 纯白物理索引卡片 + 昼夜黑曜石打字机 + 1px 极细出版物栏线 + 琥珀光聚焦行 + 页边空白伴读批注卡。

---

## 1. 业务场景匹配指南 (Scenario & Domain Affinity)

### 🎯 天然最佳业务场景 (Natural Fit)
* **长文创作与数字出版系统**：小说家、编剧、纪实作家工作台；大纲章节卡片化、人物卡片拖拽、叙事线重组。
* **卡片盒知识库与个人思考工坊 (Zettelkasten / PKM)**：原子笔记发酵、灵感卡片自由洗牌、读书笔记串联输出。
* **播客脚本、演说文稿与分镜脚本台**：按分钟/幕次切分卡片，灵活调整节奏，兼顾全局鸟瞰与逐字沉浸敲定。
* **深度专栏、调查特稿与学术论文草稿箱**：一手素材整理与长文定稿的无缝衔接。

### 🚀 降维打击 / 跨界创新场景 (Breakthrough Cross-overs)
* **重构枯燥的产品需求文档 (PRD & User Story Mapping)**：将冷冰冰的 Confluence 变成“用户故事卡片看板 + 沉浸技术规格写作”，AI 在页边空白处自动评审边缘用例。
* **法律案件卷宗梳理与辩护长文撰写**：证据事实、当事人陈述以卡片形式在案头上排列推演，理顺时间线后直接切入撰写万字辩词。
* **风险投资备忘录 (Investment Memo) 与深度研报**：财报数据卡与专家访谈碎片自由组合拼装，沉淀出装帧考究的决策备忘录。
* **团队愿景白皮书与战略叙事规划**：将死板的 KPI 表格变为有叙事温度的“战略卡片树”。

### 🚫 严格禁止场景 (Anti-Patterns / When NOT to use)
* **复杂多维透视数据库与高频财务核算 (Airtable / Excel 类)**：卡片流会导致横向字段密度不足，无法满足几百列复杂公式计算。
* **云原生运维与实时硬件监控大屏**：无法传达毫秒级发光报警与复杂网络拓扑。
* **高频促销电商与外卖交易前台**：慢节奏留白与极简灰调会直接抹杀冲动消费与促销转化率。

## 2. 视觉哲学与核心基因 (Aesthetic Philosophy & DNA)

本母体的核心不是某一个死板的界面布局，而是以下**不可动摇的案头审美基因**：
* **未漂白的暖燕麦纸底与黑曜石双模**（`#EAE6DF` 与 `#161618`）营造书卷温润感。
* **1px 极细出版物栏线（Hairline Grid）** 取代大阴影，呈现高级精装典籍的版心质感。
* **Newsreader 衬线长文 + Plus Jakarta Sans 敏捷界面 + JetBrains Mono 元数据** 的三重视觉韵律。
* **打字机段落聚光灯（Typewriter Focus）** 与 **页边伴读批注卡（Margin Notes）** 替代粗暴的全局浮动大聊天框。

## 3. 四大排版拓扑发散矩阵 (Four Layout Paradigms & Mutations)

> ⚡ **给下游 AI 的防 1:1 复刻变异指令 (Anti-Cloning Directive)**：  
> **严禁盲目套用任何单一模板！** 每次拿到本母体时，AI 必须根据实际业务形态，在以下 **4 套截然不同的排版拓扑** 中选定最匹配的一种，或取其长处进行杂交创新：

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                           Writer's Atelier 四大拓扑发散矩阵                                     │
├────────────────────────────────┬────────────────────────────────┬──────────────────────────────┤
│ 范式 A：模块化无界文档流 (Notion/Craft)│ 范式 B：古典三联案头研究台 (Scrivener)  │ 范式 C：极简禅意单栏 (iA Writer)     │
├────────────────────────────────┼────────────────────────────────┼──────────────────────────────┤
│ 范式 D：空间无界卡片白板 (Milanote/Hepta)│ 跨界杂交：自由组合（如 空间画布 + 模块流）│ 变异参数：行内AI vs 边缘AI vs 聚光灯 │
└────────────────────────────────┴────────────────────────────────┴──────────────────────────────┘
```

### 范式 A：【Notion / Craft 式】模块化无界文档流 (Block-Centric Infinite Flow)
* **设计意图**：将文档从传统的“固定卡片或边框”中解放出来，全页面就是一张连贯、无边界的数字白纸。
* **适用场景**：团队知识库、现代敏捷 PRD、多媒体混合排版笔记、个人日常 Wiki。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌──────┬────────────────────────────────────────────────────────┬──────┐
  │ 悬浮 │  [页面 Icon + 无边框巨大标题 (Newsreader 36px)]         │ 极简 │
  │ 极窄 │  :: 块 1：自由文本段落（悬停左侧出现拖拽点 :: 与 + 号）     │ 浮动 │
  │ 树状 │  :: 块 2：代码块 / 呼出 Callout（淡燕麦色底衬）          │ 目录 │
  │ 抽屉 │  :: 块 3：[/] 快捷唤出 AI 润色、表格、分栏、二级文档     │ (TOC)│
  │ (可折│  :: 块 4：行内穿插嵌入式微卡片或待办清单                │ 3-4项│
  │ 叠)  │                                                        │ 锚点 │
  └──────┴────────────────────────────────────────────────────────┴──────┘
  ```
* **核心手艺特征**：
  * **无显性卡片容器**：取消独立的卡片外框，整个视窗中心（约 720px~840px）自适应流动。
  * **Block-Level Hover 交互**：每行在鼠标悬停时左侧微弱浮现 `⋮⋮` 拖拽把手与 `+` 添加按钮。
  * **行内交互式 Inline AI**：选中文字时弹出微气泡，或按空格/`/`在光标下方展开行内辅助，不破坏纵向阅读心流。

---

### 范式 B：【Scrivener / Ulysses 式】古典书斋三联案头研究台 (Triptych Scholar Desk)
* **设计意图**：高信息密度、强结构化的严肃创作与深度研读环境，全局掌控素材与章节脉络。
* **适用场景**：长篇小说、影视分镜脚本、学术学术论文、复杂案件辩护词、长篇行业深度研报。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌───────────────┬───────────────────────────────┬───────────────────────────────┐
  │ 卷宗与大纲树   │ 沉浸稿纸主写作台               │ 伴读素材与灵感抽屉             │
  │ (Outline Tree)│ (Central Manuscript)          │ (Research Drawer / Margin AI) │
  │ 220px 极细栏线 │ 纯居中文稿，支持聚光灯行      │ 280px 右侧栏或动态弹出        │
  │ ───────────── │ ───────────────────────────── │ ───────────────────────────── │
  │ • 第一幕：起因│ # 第三章：站台交锋            │ [引用文献 / 人物小传卡片]     │
  │   - 01 迟到快车│                               │                               │
  │   - 02 密信   │ 汽笛声刺破了阴雨绵绵的站台... │ [AI 逻辑自洽性审查便签]       │
  │ • 第二幕：转折│                               │ "注意：前文提到主角右臂受伤， │
  │ • 角色小传卡  │ 琥珀色光标正在敲击此处|       │  此处不宜双手持枪。"          │
  └───────────────┴───────────────────────────────┴───────────────────────────────┘
  ```
* **核心手艺特征**：
  * **1px 发丝线严格三联屏**：左侧结构导航、中间文稿打字机、右侧素材引文库，三者由 `1px solid rgba(0,0,0,0.08)` 纯粹划分。
  * **双向对齐高亮**：中间文稿滚动到某一章节时，左侧目录树与右侧关联证据卡片自动同步聚焦。

---

### 范式 C：【iA Writer / Substack 式】极简禅意单栏打字机 (Zen Distraction-Free Flow)
* **设计意图**：剥离一切 UI 装饰与面板，将写作者的感官彻底封锁在文字与思想的呼吸中。
* **适用场景**：纯文学创作、每日心流晨间日记 (Morning Pages)、诗歌、单篇深度散文、长推特构思。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │                                                                             │
  │                        极宽负空间，顶部无任何工具条                         │
  │                                                                             │
  │               前文已写段落自动变淡 (opacity: 0.35; 铅灰)                   │
  │                                                                             │
  │               【当前正在敲击的这一句话保持 100% 对比度】                     │
  │               【伴随一抹跳动的琥珀橙打字机光标 | 】                         │
  │                                                                             │
  │               尚未展开的下文区域隐入淡雅的燕麦纸面...                       │
  │                                                                             │
  │ 极隐蔽角落元数据: Newsreader 21px / 1,480 words / 4m read                   │
  └─────────────────────────────────────────────────────────────────────────────┘
  ```
* **核心手艺特征**：
  * **绝对居中且受限的版心**：固定最大宽度 660px ~ 700px，外侧全为空白纸底。
  * **段落级聚光灯 (Typewriter Focus Spotlight)**：非聚焦区域自动退后，帮助视线锁死在当下。
  * **无干扰伴读便签**：AI 建议平时完全折叠，仅在右侧页边留一个极淡的琥珀色小圆点，写作者点击时才滑出。

---

### 范式 D：【Milanote / Heptabase 式】空间无界卡片桌与灵感织机 (Spatial Canvas & Weaver)
* **设计意图**：打破线性的条条框框，支持非线性、发散性的灵感碎片捕捉与网状空间关联。
* **适用场景**：脑暴提案、剧本多线叙事推演、卡片盒笔记发酵 (Zettelkasten)、产品故事地图 (Story Mapping)。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌───────────────────────────────────────────────────────────────────┬─────────┐
  │ 2D 无限平移漫游画布 (Pan & Zoom Canvas，燕麦色微网格纹理)           │ 浮动抽屉│
  │                                                                   │ 线性    │
  │   ┌──────────────┐          连线 (Bezier Connector)               │ 文稿    │
  │   │ 灵感碎片 A   │ ──────────────────────► ┌──────────────┐       │ 编织机  │
  │   │ "站台的雨声" │                         │ 关键转折卡 C │       │ (Weaver)│
  │   └──────────────┘                         │ "未寄出的信" │       │ ────────│
  │          ▲                                 └──────────────┘       │ 点击左侧│
  │          │                                                        │ 卡片直接│
  │   ┌──────────────┐                                                │ 拖入大纲│
  │   │ 角色动机卡 B │                                                │ 形成文章│
  │   └──────────────┘                                                │         │
  └───────────────────────────────────────────────────────────────────┴─────────┘
  ```
* **核心手艺特征**：
  * **物理索引卡片空间撒落**：每张卡片具有实体白卡质感，支持自由拖拽、打标签、连线组合。
  * **画布 ⇄ 线性双向编织**：右侧常驻或悬浮“文章编织机 (Weaver Pane)”，将画布上的卡片直接拖入右侧即可排布成一篇文章。

## 8. 核心反模式红线 (Forbidden Patterns)

* 🚫 **严禁使用刺眼弥散大阴影**：卡片以平面贴合纸面为主，严禁类似 `0 20px 40px rgba(0,0,0,0.15)` 的大阴影。
* 🚫 **严禁底部浮动大聊天框**：AI 必须以“页边空白批注卡（Margin Notes）”或“行内 Slash/气泡（Inline AI）”形式安静存在，不得遮挡正文。
* 🚫 **严禁常驻巨幅黑色/彩色重型工具条**：写作区工具条平时必须隐匿，只在光标划选文字时弹出轻量悬浮微工具条（Floating Bubble Menu）。
* 🚫 **严禁高饱和糖果杂色**：全站中性灰阶，只允许一抹极度克制的琥珀暖橙（`#E08A3C`）作为行聚焦和操作焦点。
* 🚫 **严禁单一模板思维**：AI 编写代码时，必须根据产品类型（Notion流 / 三联屏 / 极简单栏 / 空间画布）做出明确选择，禁止把所有产品都做成同一种“左导航+中卡片+右详情”的机械模板！

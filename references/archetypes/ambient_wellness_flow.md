# 视觉母体：Ambient Wellness Flow（情绪呼吸与有机心流体）

> **标杆来源**：`How We Feel` (Apple Design Award), `Calm`, `Endel`, `Headspace`  
> **核心隐喻**：活体环境生物光与有机情绪画布 (Living Ambient Canvas) + 弥散极光渐变 (Aurora Glow) + 极软超椭圆 (Smooth Squircle 24px+) + 动态呼吸光晕 (Breathing Aura) + 悬浮声波动态柱 + 减压触控回弹 (Liquid Spring Bounce)。

---

## 1. 业务场景匹配指南 (Scenario & Domain Affinity)

### 🎯 天然最佳业务场景 (Natural Fit)
* **心理情绪觉察与日记追踪 (Mental Health & Mood Journal)**：如 How We Feel，用温暖的光晕流动记录当下的喜怒哀乐与身体能量。
* **冥想白噪音与助眠音景 (Meditation & Soundscapes)**：如 Calm / Endel，全屏柔光脉冲，帮助用户在睡前彻底放松眼神经与大脑。
* **呼吸训练与正念暂停 (Breathing Exercise & Pause)**：跟着光晕的缓慢膨胀与收缩进行 4-7-8 深度呼吸。
* **女性生理周期与身体节律呵护 (Cycle & Bio-rhythm Tracking)**：柔和、去病理化的身体信号观察。

### 🚀 降维打击 / 跨界创新场景 (Breakthrough Cross-overs)
* **慢节奏小众香氛与生活美学电商 (Artisan Fragrance & Bath)**：打破常规货架式电商的喧嚣，让用户按“早晨的松木冷雾”或“雨后青草”的心境选购香氛。
* **情绪减压数字宠物与虚拟陪伴 (Virtual Companion)**：将 AI 对话界面做成随语音语调呼吸波动的发光体，极具疗愈感。
* **深夜睡前阅读与极简散文播客**：无锐角、无刺眼对比度，保护视网膜与昼夜节律。

### 🚫 严格禁止场景 (Anti-Patterns / When NOT to use)
* **紧急灾备与工业安全警报系统**：呼吸光晕缺乏尖锐刺目的警示冲击力，会导致危机响应迟缓。
* **高周转即时配送物流骑手端**：骑手在烈日强光下需要极高黑白反差与大粗体，无法看清低对比度的柔光极光。
* **财务报表多维交叉审计**：密集的十进制数据表格与流体渐变发生灾难性冲突。

## 2. 母体之魂与核心基因 (Soul & Core Ethos)

> 💡 **母体之魂**：**流动的生命之光与温柔的心灵庇护所——摒弃锐角与对抗，用生物光律动和有机超椭圆抚平精神内耗**。现代人每天被刺目的白光、冷酷的红点警报与紧绷的 Deadline 挤压；本母体将移动界面重构为一个有体温、会呼吸的光之避风港。通过慢速漂移的生物光晕（Aurora Glow）、如握鹅卵石般的超椭圆（Squircle 24px+）与同频呼吸环，引导心率回归平缓，唤醒深层平静。

* **环境生物光画布（Living Ambient Canvas）**：背景由 2~3 个有机弥散光球（Blurred Mesh Orbs）在深蓝黑夜幕中缓缓漂移，界面如活体般呼吸。
* **极软超椭圆与零锐角（Maximum Squircle）**：卡片与控件全采用 `24px ~ 36px` 柔和圆角，杜绝任何直角与心理防御。
* **情绪光谱映射（Mood Spectrum）**：用杏黄粉金代表能量释放，鼠尾草绿代表深度平静，薰衣草紫代表睡眠修复。
* **悬浮毛玻璃胶囊底坞（Glassmorphic Dock）**：通栏常驻条退场，留出空气感，光斑自缝隙自由流动。

## 3. 三大排版拓扑发散矩阵 (Three Layout Paradigms & Mutations)

> ⚡ **AI 消费指引 (学魂变骨)**：疗愈冥想绝非只有千篇一律的紫色背景！根据具体身心场景选择或组合以下骨架：

```

│                          Ambient Wellness Flow 三大拓扑发散矩阵                                 │
├────────────────────────────────┬────────────────────────────────┬──────────────────────────────┤
│ 范式 A：情绪气泡流 (HowWeFeel) │ 范式 B：正念呼吸同频舱 (Calm)  │ 范式 C：水波慢日志 (Journal) │
```

### 范式 A：【直觉觉察】How We Feel 式情绪气泡流 (Mood Bubble Matrix)
* **设计意图**：将复杂抽象的心理状态具象化为不同颜色、带有微弹力的情绪气泡选块。
* **适用场景**：早晚心情打卡、焦虑情绪疏导、身心电量评估。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌────────────────────────────────────────┐
  │                                        │
  │     How are you feeling right now?     │ ◄── 柔和 Newsreader 26px 居中
  │           "此刻你的心境如何？"         │
  │                                        │
  │   ┌────────────────┐┌────────────────┐ │ ◄── 极软超椭圆弹性气泡
  │   │ ☀️ 充满希望    ││ 🌿 深度平静    │ │     (微透半透明磨砂底)
  │   │ 杏粉金柔光     ││ 鼠尾草青柔光   │ │
  │   └────────────────┘└────────────────┘ │
  │   ┌────────────────┐┌────────────────┐ │
  │   │ 🌧️ 略感疲惫    ││ 🌪️ 焦虑纷乱    │ │
  │   │ 薰衣草紫光     ││ 雾蓝光         │ │
  │   └────────────────┘└────────────────┘ │
  │                                        │
  │   [ ⚪ ⚪ ⚪ 悬浮毛玻璃胶囊底坞 Dock ]     │
  └────────────────────────────────────────┘
  ```

### 范式 B：【沉浸同频】正念呼吸环与脉动同频舱 (Breathing Resonator Capsule)
* **设计意图**：全屏零多余控件，中央唯一巨大的呼吸光环缓慢膨胀（吸气 4s）与收缩（呼气 6s）。
* **适用场景**：睡前深度放松、惊恐发作即时平复、正念冥想。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌────────────────────────────────────────┐
  │                                        │
  │                                        │
  │                ○ 吸气 (Inhale)         │
  │           ╭───────────────╮            │
  │          │   ( 呼吸环 )   │            │ ◄── 慢速弥散脉冲
  │          │  缓慢膨胀微光  │            │     (scale: 1.0 -> 1.4)
  │           ╰───────────────╯            │
  │                ○ 呼气 (Exhale)         │
  │                                        │
  │                                        │
  │        [ 点击暂停 · 4-7-8 节律 ]       │ ◄── 极隐蔽半透明胶囊
  └────────────────────────────────────────┘
  ```

### 范式 C：【如水流动】水波日志河道 (Ripple River Journal)
* **设计意图**：日志卡片如鹅卵石般静卧在流动的生物光水面上，滑动时带有水波涟漪回弹。
* **适用场景**：生活美学记录、香氛感知体验分享、慢节奏散文伴读。
* **拓扑骨架**：单列自适应超椭圆卡片流，卡片四周带 `0.5px` 发光边缘，背景极光随着手指滚动轻盈移位。

## 6. 字体与排印规范 (Typography Tokens)

* **推荐字体**：`"Plus Jakarta Sans", "SF Pro Rounded", -apple-system, sans-serif`
* **排印风格**：
  * **主情绪大标**：`26pt ~ 32pt`，Weight 600，圆润且温情
  * **引言与提问 (Prompt)**：`17pt / 26px`，Weight 400，舒缓行高，文字色为 `rgba(255,255,255,0.85)`
  * **微元数据 (Caption)**：`13pt`，Weight 400，半透明度 `0.45`

---

## 7. 微交互与触觉规约 (Motion & Haptics)

1. **如入水般柔和触觉 (Soft Water Droplet Haptic)**：
   * 点击情绪药丸时，触发极轻软震动（`UIImpactFeedbackGenerator(style: .soft)`），如同手指探入温水；
   * 严禁机械脆感强烈的重震。
2. **液体回弹物理 (Liquid Spring Animation)**：
   * 阻尼比设置为 `0.75`，弹性质量 `1.0`，让视效如凝胶果冻般缓慢释压。

---

## 8. 核心反模式红线 (Forbidden Patterns)

* 🚫 **严禁使用尖锐 90 度直角与硬边框**：全站坚决杜绝尖锐生硬的直角，必须保持 `24px ~ 36px` 的连续曲率超椭圆（Squircle）。
* 🚫 **严禁使用高饱和度刺眼荧光色**：色彩必须如黎明或黄昏天色般经过漫反射雾化，拒绝高对比度霓虹光。
* 🚫 **严禁沉重死板的实色常驻底栏**：禁止使用类似网页端的常驻黑/白底部导航条，必须使用悬浮式半透明毛玻璃胶囊（Glassmorphic Dock）。
* 🚫 **严禁单一冥想模板套用**：AI 必须在情绪气泡选块、正念呼吸同频舱与水波慢日志河道间根据用户身心任务自如选骨！

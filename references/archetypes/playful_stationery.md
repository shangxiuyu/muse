# 视觉母体：Playful Stationery（趣味文具与复古手账流）

> **标杆来源**：`SayBriefly` (saybriefly.com), `Pitch` (pitch.com), `PostHog` (posthog.com)  
> **核心隐喻**：高级米白手账纸 + 深墨绿钢笔书写 + 荧光便利贴 + 针孔撕纸虚线 + 真实手绘涂鸦批注。

---

## 1. 业务场景匹配指南 (Scenario & Domain Affinity)

### 🎯 天然最佳业务场景 (Natural Fit)
* **自由职业 / 独立工作室协同**：合同条款确认、交付物追踪、日程管理、项目范围防扯皮。
* **个人灵感与知识库**：创意笔记、思维便签、草稿箱、灵感画板、读书手账。
* **轻量级任务看板与 Checklist**：打卡清单、敏捷便签墙、轻量 CRM、头脑风暴看板。
* **独立开发者作品集与小工具**：计算器、个人简历、创意小工具、开源产品展示。

### 🚀 降维打击 / 跨界创新场景 (Breakthrough Cross-overs)
* **传统枯燥的会议纪要（如 SayBriefly）**：将冰冷的 AI 转录文字变成带有荧光笔圈选和手绘便签的“会议手账”，瞬间破除机器冰冷感。
* **个人记账与预算规划**：做成一本带有票据撕角、印章徽章和真实手写批注的实体账本。
* **团队 Onboarding / 入职指引**：做成一本充满手绘插画、便签提示与亲切说明的新人手账。

### 🚫 严格禁止场景 (Anti-Patterns / When NOT to use)
* **超高频金融撮合与大宗交易终端**：需要极高暗调数据密度和全键盘流，不适合手账纸张质感。
* **严谨法律文书核心签署与政务系统**：需要极度中立的公文式排版，涂鸦手绘会破坏法律严肃性。
* **重型工业组态与硬件监控大屏**：需要高对比度发光指示灯和冷色仪表盘。

## 2. 母体之魂与核心基因 (Soul & Core Ethos)

> 💡 **母体之魂**：**消除严肃软件的心理压迫感**。软件不应像冷冰冰的监工，而应像一本私人抽屉里的手账本。借由米白纸张的温度、墨水渗入纸背的触感、荧光笔的随性圈画与胶带的偶发拼贴，唤醒人内在的游戏感与创作乐趣。

* **未漂白的暖米白手账纸底**（`#FCFAF5`）与墨水般浸润的 **常春藤墨绿**（`#173300`）。
* **针孔撕纸与线迹（Dashed Perforation）** 取代死板实线，模拟文具的边缘撕扯与手工缝线。
* **荧光笔柠檬黄（`#FFEB5B`）与马卡龙贴纸色** 划分信息层级，带来鲜活元气。
* **Reenie Beanie 偶发手写批注与弯曲箭头**，专为打破死板的机械对齐而生。

## 3. 四大排版拓扑发散矩阵 (Four Layout Paradigms & Mutations)

> ⚡ **AI 消费指引 (学魂变骨)**：模板只是一层皮，切勿每次都写成同一个小工具卡片！根据具体业务形态选择或组合以下骨架：

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                          Playful Stationery 四大拓扑发散矩阵                                    │
├────────────────────────────────┬────────────────────────────────┬──────────────────────────────┤
│ 范式 A：对开手账本流 (Spine Book)│ 范式 B：软木塞磁吸便签板 (Board) │ 范式 C：针孔收据清单流 (Strip) │
├────────────────────────────────┼────────────────────────────────┼──────────────────────────────┤
│ 范式 D：模块手账工坊 (Stationery)│ 变异参数：手绘箭头密度 (30%~70%)│ 杂交：如 便签板 + 撕纸收据清单 │
└────────────────────────────────┴────────────────────────────────┴──────────────────────────────┘
```

### 范式 A：【经典实体感】对开手账本流 (Spine-Bound Notebook)
* **设计意图**：模拟一本摊开在案头的高级物理手账，左右双栏带有明显的纸张装订感。
* **适用场景**：个人周计划、会议纪要对账、读书随笔、双向对照清单。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌──────────────────────────────┬───┬──────────────────────────────┐
  │ 左页：时间轴与日程大纲       │装 │ 右页：灵感涂鸦与自由便签     │
  │ (Schedule & Checklist)       │订 │ (Notes & Sticky Scribbles)   │
  │ • 09:30 产品周会 [已打钩 ✔]  │中 │  ┌──────────────────────┐    │
  │ • 14:00 方案评审             │缝 │  │ 黄色便利贴：         │    │
  │ • [虚线分割线 - - - - - -]   │   │  │ "记得提醒团队带原型" │    │
  │ • 撕角便签：本周核心目标     │ ║ │  └──────────────────────┘    │
  │                              │ ║ │   ↗ 手绘箭头指向此处         │
  └──────────────────────────────┴───┴──────────────────────────────┘
  ```

### 范式 B：【轻量协同】软木塞磁吸便签板 (Cork Pinboard / Kanban)
* **设计意图**：将传统死板的 Jira 看板变成一面充满温度的创意工作室软木板。
* **适用场景**：头脑风暴、设计冲刺灵感墙、敏捷打卡、家庭备忘录。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌─────────────────────────────────────────────────────────────────┐
  │ [顶部轻量文具胶带标题栏：Studio Board #04]                      │
  ├────────────────┬────────────────┬──────────────────────────────┤
  │ 待办 (To-Do)   │ 进行中 (Doing) │ 已完成 (Done) · 盖章印记     │
  │ ┌────────────┐ │ ┌────────────┐ │ ┌──────────────────────────┐ │
  │ │粉紫便签卡片│ │ │薄荷青便签卡│ │ │柠檬黄便签 [COMPLETED戳记]│ │
  │ │微斜倾角 -1°│ │ │胶带粘角    │ │ │撕纸边缘虚线              │ │
  │ └────────────┘ │ └────────────┘ │ └──────────────────────────┘ │
  └────────────────┴────────────────┴──────────────────────────────┘
  ```

### 范式 C：【极简流水】针孔收据清单长流 (Perforated Receipt Strip)
* **设计意图**：如同超市小票或复古打孔发票，垂直自顶向下打印，每一项都可沿针孔撕下。
* **适用场景**：每日打卡清单、记账账单、个人随手记、极简小工具。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌────────────────────────────────────────┐
  │           ==== RECEIPT ====            │
  │  2026-09-16 · 08:30 AM · STORE #01     │
  │ - - - - - - - - - - - - - - - - - - -  │ ◄── 针孔虚线剪切处
  │  [ ] 晨间咖啡与 10min 冥想             │
  │ - - - - - - - - - - - - - - - - - - -  │
  │  [✔] 提交 Muse 母体设计规范   $0.00    │ ◄── [STAMP: APPROVED 印章]
  │ - - - - - - - - - - - - - - - - - - -  │
  │  [ ] 傍晚给阳台植物浇水                │
  │                                        │
  │   |||||||||||||||||||||||||||||||||    │ ◄── 底部复古条形码装饰
  └────────────────────────────────────────┘
  ```

### 范式 D：【现代工坊】模块化手账文档流 (Stationery Modular Stream)
* **设计意图**：结合 Notion 的结构化块级排版与文具的纸质温度，适合承载复杂长篇内容。
* **适用场景**：独立开发者文档、自由职业者服务报价单、产品 Onboarding 导引。
* **拓扑骨架**：居中 760px 页面，每个段落左侧有文具图章图标，Callout 块直接渲染为贴在纸上的大便利贴，带真实胶带（Washi Tape）粘痕。

## 4. 字体与排印体系 (Typography Tokens)

```html
<!-- 引入 Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">

<link href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,700;800&family=Inter:wght@400;500;600&family=Reenie+Beanie&family=Roboto+Mono:wght@400;500;700&display=swap" rel="stylesheet">
```

| 角色 | 推荐字体 | 字重/样式 | 尺寸与行距 | 用途与排印规约 |
| :--- | :--- | :--- | :--- | :--- |
| **大标题 (Display)** | `Bricolage Grotesque` | 700 / 800 | `36px ~ 72px` (line-height: 1.1) | 饱满、有张力、带复古怪诞性格，负字距 `-0.02em` |
| **正文 (Body)** | `Inter` / `Source Sans 3` | 400 / 500 | `16px ~ 20px` (line-height: 1.6) | 保证大段阅读清晰度，颜色使用深墨绿而非纯黑 |
| **手绘批注 (Handwriting)** | `Reenie Beanie` | 400 (Italic feel) | `22px ~ 32px` | 配合手绘箭头做边栏批注、旁白、圈注 |
| **票据/元数据 (Mono)** | `Roboto Mono` | 400 / 700 | `13px ~ 15px` | 用于价格标签、对比表格、时间戳、胶囊徽章 |

## 7. 核心反模式红线 (Forbidden Patterns)

* 🚫 **严禁使用现代冷灰与纯蓝纯黑**：背景禁 `#F3F4F6`，文字禁 `#000000`，必须沉淀在米白纸张与常春藤墨绿中。
* 🚫 **严禁生硬死板的实线外框**：大面积分割线必须使用针孔虚线或点状线。
* 🚫 **严禁过多无意义涂鸦喧宾夺主**：手写字体与箭头仅在 10%~20% 的关键情绪点缀处使用，核心数据正文必须保持 Inter / Roboto Mono 的清晰可读。
* 🚫 **严禁单一模具套用**：必须根据产品性质在对开本、便签板、收据长流与模块工坊中自由选骨！

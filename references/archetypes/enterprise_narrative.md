# 视觉母体：Enterprise Narrative（现代企业叙事与矢量工装风）

> **标杆来源**：`Allwhere` (allwhere.co), `Stripe` (stripe.com), `HashiCorp` (hashicorp.com)  
> **核心隐喻**：工业工程严谨性 + 概念矢量叙事插画 + 溢出式微缩真实数据卡片（Escaped UI） + 荧光笔刷漆动效。

---

## 1. 业务场景匹配指南 (Scenario & Domain Affinity)

### 🎯 天然最佳业务场景 (Natural Fit)
* **现代 B2B 企服与全球供应链**：IT 设备资产管理、企业级采购与物流、跨境合规与结算。
* **人力薪酬与团队基础设施**：全球员工 Onboarding、薪酬福利分发、混合办公设备追踪。
* **开发者云平台与微服务网关**：API 计费中枢、数据管道监控、多云资产管理。
* **安全审计与合规平台**：SOC2/GDPR 自动化审计、权限管控中心。

### 🚀 降维打击 / 跨界创新场景 (Breakthrough Cross-overs)
* **传统极其沉闷的 ERP / OA 审批流**：用清爽的青瓷蓝、IBM Plex 工装字体与破框微缩卡片，把传统枯燥的后台变成极具科技感与愉悦感的现代工装平台。
* **企业级数据看板与 ROI 计算器**：用自下而上刷漆的荧光笔动效和多层柔和物理阴影，把原本死板的数字报表变成动态增长故事。

### 🚫 严格禁止场景 (Anti-Patterns / When NOT to use)
* **极度个人化的艺术作品集 / 摄影展**：过于偏向现代工业协同感，缺乏个人私密情绪。
* **赛博朋克 / 3D 沉浸式游戏社区**：严谨的 IBM Plex 字体与清爽冷色调不符合暗黑重噪点氛围。

## 2. 母体之魂与核心基因 (Soul & Core Ethos)

> 💡 **母体之魂**：**将复杂、繁冗且冰冷的 B2B 企业工程，重塑为清晰、可信、有尊严的现代商业叙事**。摒弃老旧 ERP 带来的疲倦与压抑感，通过 IBM Plex 的严密工程理性、清爽的青瓷水蓝与破框溢出的真实数据切片（Escaped UI），让每位操作者感受到精密工业生产力的高级质感。

* **工程理性与清晰度**：采用方正坚毅的 `IBM Plex Sans` 配合大写工装按键（如 `RUN AUDIT`）。
* **破框溢出微缩卡片 (Escaped UI)**：核心视窗永远拒绝死板呆盒，图表与数据切片必须溢出 20px~40px 形成层次叠落。
* **青瓷冰川蓝（`#8FC8CF`）与点睛暖珊瑚橙（`#F27058`）** 的冷暖严谨平衡。
* **荧光笔刷漆微动效 (Sweep Motion)**：鼠标滑过时自下而上刷漆高亮，给严肃工业注入敏捷巧思。

### 范式 A：【品牌与驾驶舱】破框数据舱 (Escaped UI Command Center)
* **设计意图**：概念插画与真实数据卡片相互交织，形成强烈的 2.5D 现代工业视觉冲击。
* **适用场景**：现代化企服 SaaS 官网、高管大盘总览、云基础设施核心入口。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ [极简顶部导航：全大写产品矩阵 + 暖珊瑚橙 CTA: "GET A DEMO"]                 │
  ├──────────────────────────────────────┬──────────────────────────────────────┤
  │ 左侧：叙事文案与指标                │ 右侧：大型中枢画布 + 破框溢出数据切片│
  │ • IBM Plex 64px 严谨工装大标题      │ ┌──────────────────────────────────┐ │
  │ • 荧光刷漆关键字: [SOC2 Compliance] │ │ 核心拓扑连接图                   │ │
  │ • 两组关键 ROI 数字 (Mono 28px)     │ └──────────────────────────────────┘ │
  │                                      │  ┌──────────────────────────┐ (破框) │
  │ [全大写胶囊按钮：DEPLOY AGENT →]     │  │ 溢出浮层：实时审计通过卡 │ (溢出) │
  │                                      │  └──────────────────────────┘ (30px) │
  └──────────────────────────────────────┴──────────────────────────────────────┘
  ```

### 范式 B：【高频生产力】致密双流分工工作台 (Dense Split Workbench)
* **设计意图**：左侧保持极高的数据密度与键盘快捷操作，右侧无模态平滑滑出详细核算与审批流。
* **适用场景**：采购清单审批、跨境资金合规审核、IT 资产设备生命周期管理。
* **拓扑骨架 (ASCII Layout)**：
  ```
  ┌──────────────┬───────────────────────────────┬──────────────────────────────┐
  │ 左侧紧凑菜单 │ 中间：高密度表格/卡片流       │ 右侧：展开式无遮挡决策抽屉   │
  │ (Collapsed)  │ (High-Density Data Grid)      │ (Sliding Action Drawer)      │
  │ • 设备采购   │ [筛选器: All / P0 / Pending]  │ ───────────────────────────  │
  │ • 员工资产   │ ┌───────────────────────────┐ │ 订单 #PO-98421 详细核验      │
  │ • 权限审计   │ │ 订单号 / 供应商 / 金额 /状态│ │ [青瓷蓝标签: 需 CFO 批准]    │
  │              │ ├───────────────────────────┤ │ 工装按钮：[REJECT] [APPROVE] │
  │              │ │ #98421 / Apple / $32,000  │ │ 数据差异分析条形图         │
  └──────────────┴───────────────────────────────┴──────────────────────────────┘
  ```

### 范式 C：【战略全景】叙事 Bento 网格看板 (Executive Narrative Bento)
* **设计意图**：为管理者整合多业务线事实，将图表与文字解释咬合在同一组现代 Bento 卡片中。
* **适用场景**：季度战略复盘、全公司碳排放与合规监控、多云成本控制仪表盘。
* **拓扑骨架**：由 4~5 个非对称的 Bento 单元组成，每个单元左上角配有青瓷蓝工装徽章，右下角配微折线图与指标对比。


| 角色 | 推荐字体 | 字重/样式 | 尺寸与行距 | 用途与排印规约 |
| :--- | :--- | :--- | :--- | :--- |
| **大标题 (H1/H2)** | `IBM Plex Sans` | 600 / 700 | `36px ~ 64px` (line-height: 1.15) | 严谨工程感，字偶距自然，采用 `text-wrap: balance` |
| **正文 (Body)** | `IBM Plex Sans` | 400 | `16px ~ 18px` (line-height: 1.55) | 极致清晰的抗锯齿与易读性，石墨灰颜色 |
| **大写行动按键 (CTA)** | `IBM Plex Sans` | 600 / 700 | `14px ~ 15px` (letter-spacing: `0.05em`) | 全大写如 `GET A DEMO`，配合圆角矩形 |
| **数据与指标 (Data)** | `IBM Plex Mono` | 600 | `14px ~ 28px` | 采购订单号、工时统计、金额指标 |

## 7. 核心反模式红线 (Forbidden Patterns)

* 🚫 **严禁呆板无趣的四方盒禁锢**：绝对禁止所有模块都整齐划一塞在无聊网格内，必须在核心模块制造至少一处 20px~40px 的破框悬浮（Escaped UI）。
* 🚫 **严禁使用模糊发散的大阴影**：使用精密物理衰减三层微阴影，杜绝浓黑泥浆感。
* 🚫 **严禁花哨圆体或过度装饰字体**：坚决贯彻 IBM Plex 系列的现代工业工程严肃性。
* 🚫 **严禁单一后台模板套用**：必须在破框数据舱、双流工作台与全景 Bento 间根据业务场景自如切换！

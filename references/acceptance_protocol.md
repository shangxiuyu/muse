# 成品验收：以观察证据决定是否通过

验收对象是实际成品，不是代码意图、规则数量或创作者解释。先保存 brief、原始素材、作品契约、成品和观察条件，再开始评审。

## 观察层级

| 声明 | 最低证据 |
|---|---|
| 文件生成 | 文件存在且可打开 |
| 图像满足要求 | 实际看图核对主体、文字和目标版位，并检查文件规格；编辑前后比较保留项，系列并排比较识别线索 |
| 页面渲染 | 在目标环境实际打开并观察 |
| 响应式成立 | 至少观察主要宽度与一个窄屏，核对内容和任务是否保留 |
| 交互可用 | 在目标环境实际完成主要路径，并观察成功、失败或返回状态；原生控件以解析后可见的选项和入口为准 |
| 动效成立 | 在运行中观察开始、中间和结束，而非只检查 animation 属性或 class |
| 内容可信 | 对照内容账本和实际读取的来源逐项核对 |
| 纯文本改写成立 | 对照原文核对事实、限定、责任与作者声音，并实际扫读、朗读 |
| 规约可检验 | 每条规则都能构造出「这样做就违规」的反例场景，并实际拿去对话试探 |
| 无障碍通过 | 使用相应检查与操作；只有对比度或焦点源码不足以证明整体通过 |

没有达到相应证据时写“未验证”，不能用“代码已实现”“控制台无报错”替代。

## 分开记录四种结论

审美复核不能用一个总分混合不同性质的判断：

- **审美力量**：记录观察到的秩序、张力、具体性、共鸣线索与余韵；没有人的反馈时只称审美假设得到形式证据支持。
- **设计适切**：记录任务、理解、阅读、操作、媒介和环境是否成立。
- **伦理完整**：记录事实、来源、操纵性表达、人的自主性与可访问性风险。
- **个人共鸣**：只引用用户实际反应或已授权的品味资产；AI 预测不能冒充用户感受。

四者可以互相影响但不能互相证明。好用不自动等于美，有感染力不自动等于诚实，用户喜欢也不自动成为普遍规则。

## 阻断项

出现任一项，成品不能以“通过”交付：

- 作品承诺、主要任务与实际行为冲突。
- 主要动作、反馈或必要信息不可获得、不可辨认或只在创作者解释中存在。
- 核心判断只在开头或结尾被声明，删掉它之后正文仍然各自成立（判断未进入结构）。
- 源码声明了关键选项、标签或分支，但目标环境解析后用户没有对应入口。
- 未标记的虚构数据、来源、人物、地点、指标、功能或未经支持的推断。
- 标题或正文因换行、裁切、缩放、对比或过小字号而破坏意义和阅读路径。
- 移动端、导出或静态替代删除了必要内容、披露或功能。
- 请求的交互或运动被声称完成，但在实际操作或播放中无法感知其作用。
- 把未执行的检查、未打开的来源或脚本无法覆盖的范围报告为已验证。

阻断项不能被整体平均分、视觉风格或其他功能抵消。

## 视觉与阅读检查

在真实内容和目标尺寸下检查：

- 缩览时，第一注意点是否对应主要主张或任务。
- 标题换行是否形成可读短语；是否出现孤字、标点悬挂、意外四五行或正文般的标题块。行数没有统一上限，但必须解释其作用并在主要断点复看。
- 正文、标签、来源和控件是否在实际观看距离可读。达到对比度不等于字号、行宽和密度合理。
- 对屏幕界面记录有效文本的 computed font-size。低于 12px 作为强制复看线索；低于 10px 的文字不能独自承载金额、日期、来源、状态、操作或披露等必要信息。它不是 WCAG 声明，也不适用于纯装饰字形、超大密度专业设备或用户明确接受的特殊场景。
- 在 100% 与 200% 文字缩放下复看主要路径。不要用浏览器截图缩放后的“还能看见”代替正常观看距离下的阅读。
- 去掉颜色和装饰后，分组、先后、状态与证据关系是否仍成立。
- 图像、图形和动效是否承担内容、行为或品牌职责；换成任意素材仍成立时，辨识度可能来自模板。
- 与近期不同类型产物并排比较，若持续复用相同色温、展示字体、构图和装饰语法，重新检查概念是否由任务产生。文化、营销和消费新作至少说明一个不能无损移植到近期作品的结构关系或视觉载体；说明不成立时降低“辨识度”判断，不靠换色算创新。

## 审美假设与差异化证据

完整新 UI、明显改版或以审美方向为主要目标的任务，还需保存 [UI 审美综合](toolkit/ui_aesthetic_synthesis.md) 中实际改变设计的最小证据：Content DNA、核心张力、结构假设、Distinctive Relation（可为 none）、Restraint Rule、取舍和验证条件。它们是可被推翻的设计依据，不是要求用户认可的长篇说明。

- **归因**：至少一个关键形式关系能够追溯到当前内容、任务或品牌事实。
- **替换**：隐藏名称、替换主图或换成另一项目后，记录哪些结构仍成立、哪些不再成立；若全部可无损迁移，不把换色或装饰称为辨识度。
- **三层比较**：分别检查表层语言、结构语法和情绪基调，避免只证明色值不同。
- **克制**：辨识关系存在时可被感知，但没有扩散到所有组件和状态；成熟高频模式因可用性被保留，或辨识关系为 none 时，应明确说明依据。
- **多元性**：不以是否极简、克制、留白多作为美的代理指标；只检查所选语言是否适合当前关系并得到真实媒介证据支持。

没有人的真实反应时，只能报告审美假设在形式上得到支持、被削弱或仍未验证，不能声称作品已经被证明为美。

## 响应式语义连续

窄屏不是几何无溢出测试。逐项核对主要动作、事实限定、来源、演示声明、错误和恢复路径。允许重排、折叠和渐进披露，但用户必须能够获得等价信息并完成主要任务。

## 演示的相遇验收

演示按 [相遇与淘汰](toolkit/presentation/encounter_and_rejection.md) 先隐藏设计理由观察实际成品，再核对事实、来源、可见内容与讲者备注。文件打开、回读、逐页渲染和编辑性属于生产底线，不能替代替换测试、生命张力、跨页节奏和用户真实反应。需要可编辑原生对象却交付整页图像、文件打不开或未渲染即声称完成，仍是阻断项；技术通过不得命名为审美“通过版”。

## UI 版本、分支与资产

持续设计任务按 [UI 迭代协议](toolkit/ui_iteration_protocol.md) 将验收证据绑定到具体目标、方向和版本，不能用另一个分支的截图或操作结果替当前版本证明通过。前后比较保持内容、尺寸、状态和任务一致；用户选中某个方向只证明选择发生，不证明其事实、可用性或无障碍已经通过。

按 [UI 资产协议](toolkit/ui_asset_protocol.md) 检查最终成品：真实 Logo 在预期位置实际可见；临时参考没有未经授权进入成品；内容素材成功加载并适配裁切；placeholder/demo 的性质没有在关键断点丢失。仅上传、传参或在源码中出现资产地址不能证明最终渲染正确。

## 纯文本的观察

文章、报告、公告和文案不因没有视觉界面而免于观察。先逐段对照内容账本和原稿，再按 [文本质量复核](toolkit/text_quality_protocol.md) 检查段落推进、扫读、朗读、作者声音与克制。检测模式只报告可定位现象；改写模式还要确认没有新增事实、改变因果或承诺、磨平作者特征。作者声音只能对照当前样本或个人库中适用的 `author_voice`；两者都没有时只能说明与本次方向一致，不能声称“像作者本人”。

**核心判断的兑现检查**（不看文字，看结构）。表达层查不出空洞，这一步才查得出：

1. **删题测试**：把契约里的核心判断那一句从文中删掉，然后只读中段。剩下的段落还能各自成立吗？如果只有开头和结尾提到它、中段与它无关，说明判断只是被贴了两次、没有进入结构——文字再干净也属阻断项。
2. **可反驳测试**：把核心判断单独念给没看过原文的人。有没有人能合理反对？无人能反对就是话题，作品正确而空洞。

两项都不通过时，返工位置是结构而不是措辞：先重立判断，再让每一段都去兑现它。这与演示的〈解释依赖测试〉是同一条原则的文本形态——拿掉声明之后，作品自身还能不能传递那个判断。

## 规约型文本的观察

提示词、SOP、检查表这类**给模型或流程执行的**文本，不能用「读起来如何」验收。逐条把契约里的〈反例场景〉拿去实际触发：规则未生效就是未通过，与文字是否干净无关。构造不出反例的规则本身即为空洞，退回重写。规约的文字层检查用 `--genre spec`——它关掉与规约写法冲突的规则，并把引号内被提及的短语排除在外，避免把「不许写『很好的问题』」判成犯了这条毛病。详见[文本质量复核](toolkit/text_quality_protocol.md)第四节。

## 运动的感知检查

先写清运动的职责：状态变化、空间连续、操作反馈、注意引导或叙事情绪。实际播放后记录：

1. 用户能否看见变化，何时开始、何时结束。
2. 变化是否让状态或关系更清楚，而非只证明存在 CSS 动画。
3. 高频操作是否及时，长入场是否阻碍阅读，循环装饰是否抢占注意力。
4. 减弱动效、动画失败或静态截图下，必要内容是否仍然存在。

截图只能证明某一帧；computed style 只能证明浏览器接受属性。两者都不能单独证明动效体验。

## 独立复核

完整新作和高影响交付优先由未参与生成的观察者复核。观察者只获取 brief、原始素材、作品契约与成品，不先阅读创作者的设计理由。没有第二观察者时，用一次隔离复核：先隐藏设计说明，只按阻断项和任务路径检查，再打开说明核对取舍。

验收记录至少列出：实际观察的环境与尺寸、完成的路径、核对的来源、播放的动效、发现的阻断项和未验证范围。创作者自评与独立复核分开记录。

# 演示相遇与淘汰：先看作品，再看理由

技术完成与审美成立分开验收。文件能打开、对象可编辑、没有溢出，只证明生产底线；不能证明作品有审美力量。

## 隔离观看

先隐藏 brief、设计说明和制作过程，在整套缩览与目标尺寸下观察：

- 两秒内先看到什么；
- 目光如何移动，哪里真正停下；
- 哪些页面推进、压迫、释放、转向或留下余韵；
- 记住的是内容关系，还是一种熟悉模板；
- 近看是否出现廉价、机械、怯懦或无意冲突。

随后再打开事实、来源和设计理由，检查形式是否真的兑现命题。

## 五个淘汰测试

1. **替换测试**：隐藏名称并换成另一主题。若结构、气质和大部分页面不受影响，方向缺乏具体性。
2. **安全答案测试**：它是否只是模型最容易生成的米白背景、无衬线大字、卡片网格、蓝色强调或三栏比较？常见形式不是原罪，但必须有当前内容的理由。
3. **生命张力测试**：除整齐之外，是否存在可感知的尺度、密度、方向、材料或时间张力？若没有，回到视觉方向，而不是增加装饰。
4. **跨页节奏测试**：缩览是否有重复、变化、停顿和转折，还是同一页面语法连续复制？
5. **解释依赖测试**：拿掉设计说明后，画面还能让核心关系被感知吗？不能就说明理念没有进入形式。

## 返工顺序

发现平庸时不要先换色、加图标或随机改布局：

1. 回到真实内容，补足人物、冲突、证据或材料；
2. 推翻无效视觉命题，重新提出竞争方向；
3. 在代表页验证新的结构关系；
4. 再扩展整套节奏；
5. 最后处理制作细节和文件验证。

## 人的反应

用户说“丑”“假”“像模板”“没感觉”就是有效的相遇证据。先承认反应并定位具体对象，不用无溢出、可编辑、符合规范或“尚未学习你的偏好”为作品辩护。

诊断使用：**实际观察 → 造成的感受或理解影响 → 可能原因 → 最小有效修改 → 再次相遇**。原因不明可以保持 unknown。只有用户授权长期保存时才记录 reaction；一次反应先约束当前作品，不自动变成普遍审美规则。

## 生产底线

审美返工不能破坏事实、来源、必要限定、可读性和用户要求的交付属性。专业演示执行器仍需重新打开成品、回读文字和备注、渲染全部页面并检查文件；这些检查只报告各自覆盖的范围，不再以“通过版”暗示审美已经通过。

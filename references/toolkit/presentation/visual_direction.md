# 演示视觉方向：让内容长出形式

视觉方向不是风格名、色板或模板。它是一条能预测多项选择的命题：**因为当前内容存在某种不可替代的关系，所以整套演示以某种方式进入、组织、变化并停下。**

## 先找到内容的力

只记录会改变形式的事实：

- 主角是谁或是什么；
- 最重要的关系、冲突或转变；
- 时间、尺度、密度与可信依据；
- 真实材料与文化线索；
- 什么不能被另一主题无损替换。

不要为填表制造 Content DNA。若内容本身抽象或贫乏，先寻找真实案例、人物、证据或物质载体；找不到时承认表现空间有限，不用装饰伪造具体性。

## 方向必须预测形式

一个有效方向至少影响其中三项：

- **构图**：稳定轴、偏置、遮挡、出血、聚散或空间深度；
- **尺度**：什么被放大到身体可感，什么退成低声证据；
- **字体声音**：文字是声明、档案、对话、标注还是材料；
- **图文关系**：图像证明、冲突、延伸还是反驳文字；
- **跨页节奏**：重复、加速、停顿、突变与回声；
- **材料感**：纸张、屏幕、摄影、图表、手迹或对象为何属于这个主题。

只能预测颜色或圆角的方向无效。

## 生成真正不同的方向

方向之间的差异必须重写页面构成与叙事节奏，而不是给同一网格换皮换色。同一主题可以分别处理为“权威克制 · 精密数据拓扑”“现代纸感 · Bento 模块叙事”“高反差 · 极简大字报舞台”——它们的构图、尺度、字体声音与跨页节奏都不相同。

**门禁动作**（提出 3 组竞争假设 → 各渲染前 2 张真实 HTML 样张 → 用户选定后才扩展整套）定义在[演示与演说实战手册](../presentation_tool.md)第二节，此处不重复。方向在代表页中无法被感知，就不要扩展整套。

## 参考的使用

寻找参考时按问题而不是风格标签检索：谁处理过相似的尺度、证据、身体感、文化材料或时间关系？提取作用机制，不复制 Logo、字体文件、摄影或品牌资产。没有实际看到参考，不声称“参考了某设计师”。

## 选择与克制

方向选择写清并承担明确代价：

- 它揭示了什么；
- 它在哪一处产生张力；
- 哪些通道保持安静；
- 它牺牲了什么；
- 什么现象会证明方向失败。

成熟不是把所有元素都做得有设计感，而是让少数决定彼此支持。若字体、颜色、构图、图像和动效同时高声，删到主角重新出现。

# UI 交互：任务、状态与高阶交互兵器库

用于有导航、查找、输入、编辑、状态管理或需要提供惊艳微交互（WOW Factor）的界面。

---

## 一、任务先于组件（核心原则）

- **动作就近原则**：说明对象是什么、用户能对它做什么、结果出现在哪里。动作放在所属对象或当前选择附近；主要动作文字使用明确动宾短语描述结果（如“导出数据”而非“确定”）。
- **破坏性操作安全网**：高频低险操作保持稳定无阻，破坏性/高后果动作必须具备确认弹窗或可行的 5 秒撤销（Undo Toast）。
- **状态持久化与 URL 语义**：切换页面/详情后，按任务保留筛选、排序、分页或草稿；真正需要分享和回退的状态写入 URL Search Params，临时交互弹层不滥写地址。

---

## 二、状态形成完整路径（7 态完备性）

| 功能模块 | 需要设计的状态流转 | 真实走查重点 |
|---|---|---|
| **搜索／筛选** | 初始空态 ➔ 异步查询中 ➔ 结果列表 ➔ 无匹配结果 ➔ 查询失败 ➔ 一键重置 | 查询组合实时响应；无结果时提供清除条件入口；绝不卡死。 |
| **表单录入** | 初始 ➔ 正在编辑 ➔ 实时校验 ➔ 提交中 (Button Loading) ➔ 成功 / 失败 | 显式 `<label for="...">`；行内就近报错；提交失败保留已输入内容。 |
| **异步动作** | 待触发 ➔ 执行中 ➔ 完成反馈 (Toast) ➔ 异常处理 ➔ 状态撤销 | 防重复点击节流；状态明确在操作对象旁展示，而非单纯全屏闪烁。 |
| **导航／模态窗** | 打开 ➔ 焦点捕获 ➔ 内部交互 ➔ Escape 关闭 ➔ 焦点正确归位 | 弹窗打开锁定背景滚动；关闭后焦点回到触发按钮；支持键盘 Esc。 |
| **高密数据页** | 正常加载 ➔ 骨架屏占位 ➔ 首次空数据引导 ➔ 部分授权结果 | 骨架屏尺寸严格对齐真实布局；严禁通用旋转小菊花 Spinner。 |

## 三、THE CREATIVE ARSENAL（高阶交互兵器库实现规范）

在需要增强产品的高级质感与微动效能量感时（`MOTION_INTENSITY > 5`），按需采用以下高阶交互原型：

### 1. Spotlight Border Card（光标追踪聚光边框）
- **视觉效果**：卡片边框具备单像素微光，随着光标在卡片上移动，在光标下方呈现柔和径向聚光反射（Radial Highlight）。
- **实现标准**：
  ```css
  /* 监听 mousemove 更新 CSS 变量 --mouse-x, --mouse-y */
  background: radial-gradient(600px circle at var(--mouse-x) var(--mouse-y), rgba(255,255,255,0.06), transparent 40%);
  ```
- **性能红线**：必须使用 CSS 变量或 Framer Motion `useMotionValue` 更新坐标，**严禁在 React `useState` 中高频更新坐标**。

### 2. Liquid Glass Refraction（真折射毛玻璃）
- **视觉效果**：物理级玻璃折射感，超越单薄的 `backdrop-blur`。
- **实现标准**：
  - 模糊基底：`backdrop-blur-md bg-white/5`（深色轨）或 `bg-white/80`（浅色轨）；
  - 物理内折射边框：`border: 1px solid rgba(255, 255, 255, 0.12)`；
  - 顶部微透高光：`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.15)`。

### 3. Magnetic Physics Button（微物理磁吸按钮）
- **视觉效果**：光标接近按钮边缘（如 40px 内）时，按钮以自然弹簧阻尼向光标方向产生轻微位移吸附（5~10px）。
- **实现标准**：
  - 必须使用 Framer Motion `useMotionValue` + `useTransform` + 弹簧弹力参数（`stiffness: 150, damping: 15`）；
  - 移出范围时光标平滑回弹归零。

### 4. Dynamic Island / Morphing Pill（形态变换胶囊）
- **视觉效果**：胶囊状的小巧状态条在触发动作或收到通知时，以弹性动画平滑展开为详细信息面板或操作栏。
- **实现标准**：
  - 借助 Framer Motion 的 `layout` 与 `layoutId` 实现共享元素尺寸形变；
  - 内部文字与图标使用 `<AnimatePresence mode="wait">` 做微淡入淡出，防止形变时内容拉伸变形。

### 5. Kinetic Stagger Cascade（非均质瀑布流阶梯入场）
- **视觉效果**：列表或卡片网格挂载时，绝不齐刷刷生硬弹出，而是自上而下或呈对角线依次入场。
- **实现标准**：
  - CSS 方式：`animation-delay: calc(var(--index) * 60ms)`；
  - Framer 方式：父级 `variants: { show: { transition: { staggerChildren: 0.06 } } }`。

### 6. Text Scramble Decoder（精密字符解码）
- **视觉效果**：标题在首屏加载或用户悬停时，随机字符（如 `!@#$%^&*`）以 30ms 间隔高速闪烁，最终解码稳定为真实文字。
- **适用场景**：极客控制台、AI 生成中状态、高端科技 Landing Page Hero 标题。

## 四、输入控制、反馈与无障碍铁律

1. **显式焦点环保护**：所有表单与按钮必须保证 `:focus-visible` 具备 2px~4px 高对比度轮廓线，严禁 `outline: none`。
2. **触控与移动端靶心**：移动端触控目标必须保持 `>= 44×44px` 物理碰撞面积，相邻交互间距 `>= 8px`。
3. **动效一票否决**：必须在 CSS 或动画库中支持 `@media (prefers-reduced-motion: reduce)`，在用户开启减弱动效时直接呈现最终静态状态。

# 摄影：曝光、构图、光线与叙事

摄影不是把对象拍清楚，而是用取景、时间、距离、光线和颜色决定观看者如何进入现实。先明确图像职责：事实证据、人物身份、产品材质、空间秩序、街头瞬间、情绪或叙事。

## 曝光三角

- **光圈**控制进光量与景深。大光圈（较小 f 值）强化主体分离和近距离情绪；小光圈（较大 f 值）保留环境结构。
- **快门**控制时间。高速凝固动作；慢速把移动写成拖影、流动和时间痕迹。
- **ISO**提高感光也增加噪点。噪点可以是纪实或粗粝语言，但不要拿技术缺陷冒充情绪。

三者必须围绕叙事取舍：需要看清环境时，不应只为了“电影感”把景深压得过浅；需要时间痕迹时，轻微运动模糊可能比绝对锐利更准确。

## 构图选择

使用中心、三分、散点、对称、对角、引导线、曲线、三角、框景、留白、重复、前景、开放、封闭或填充构图时，说明它安排了怎样的主体—环境关系。黄金比例 1:1.618 可作校正工具，不是成功证明。

复看四件事：主体是否在正确位置；背景是否产生无意干扰；画外空间是否支持动作方向；边缘裁切是否有意。

## 九种光位及其叙事倾向

| 光位 | 主要效果 | 常见用途与风险 |
|---|---|---|
| 逆光 | 轮廓、透明、距离、记忆感 | 容易丢失面部与材质证据 |
| 侧逆／轮廓光 | 分离主体、制造锋利边缘 | 过强会像无理由的商业特效 |
| 顶光 | 权力、正午、压迫、雕塑感 | 眼窝与细节可能过黑 |
| 侧光 | 体积、纹理、冲突、戏剧 | 两侧信息不平衡 |
| 前侧光 | 兼顾体积与可读性 | 稳妥但可能缺乏明确态度 |
| 伦勃朗光 | 人物心理、沉静、经典肖像 | 不适合要求完全均匀的证件式信息 |
| 正面光 | 清晰、直接、平面化 | 体积与材质变弱 |
| 蝴蝶光 | 面部轮廓、时尚与精致 | 容易变成陈旧美容范式 |
| 底光 | 异常、恐惧、非现实 | 叙事理由不足时显得廉价 |

光位之外，还要检查光质、色温、环境反射和接触阴影。光源方向不一致会直接破坏真实感。

## 六类摄影关系

- **纪实**：尊重现场关系与偶发瞬间；构图可以精准，但不能把摆拍当事实。
- **建筑**：用轴线、重复、尺度、光影和人的参照解释空间，而非只拍立面。
- **时尚**：服装、身体、姿态、场景和观看关系共同构成身份；造型不能与人物状态脱节。
- **风景**：天气、时间、地貌和尺度是主角；减少旅游明信片式饱和与无差别广角。
- **静物／商业**：材质、接触面、尺度和光的方向是证据；概念道具必须强化产品关系。
- **街头**：等待动作、层次、偶然并置和公共空间关系；不以猎奇替代人的尊严。

## 十种作者策略

- 把现实当成版式：通过建筑轴线、人的位置和图形关系组织现场；
- 把身份设计成场景：环境、服装、道具和姿态共同揭示人物，而非只靠面部；
- 把城市拍成情绪：天气、色温、反射和孤独尺度共同构成心理空间；
- 在普通生活中等待诗意：幽默、温情和偶然关系优先于宏大事件；
- 让颜色成为结构：色块负责连接前后景、分组角色和引导视线，不只是调色；
- 用极简承载气氛：减少对象，但让距离、空气、光和色温足够具体；
- 用暖色建立亲近：柔光与低压状态支持治愈感，避免全局橙黄滤镜；
- 用颗粒、晃动与失焦写疏离：技术不完美必须对应城市经验和身体不安；
- 用私人距离处理欲望、生死或亲密：强烈主观性需要伦理意识；
- 用低控制感表现青春：自然光、偶发动作和胶片质感背后仍需选择与编辑。

## 色彩与后期

先找画面中的主色关系，减少无职责色彩，再用一处强调色建立焦点。暖色倾向亲近、活力和记忆；冷色倾向距离、秩序和孤独；黑白会放大形状、光和时间感。降低饱和度会暴露构图和材料问题，不自动产生高级感。

后期不应抹掉拍摄时的光线逻辑。肤色、产品色与事实证据优先；纪实作品不要通过移除关键对象改变事件含义。

## 交付前复看

1. 缩略图看第一眼主体；
2. 100% 看焦点、噪点、边缘、合成与文字；
3. 灰度看明暗结构；
4. 成组图片看色温、距离、节奏与叙事连续；
5. 回到用途检查：它是在提供证据、建立身份、说明空间，还是只制造了气氛。

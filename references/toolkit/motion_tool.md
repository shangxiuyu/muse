# 时间与运动

运动承担反馈、空间连续性、注意力或情绪。写不清这段运动在解释哪种变化，就静止。实现提示见 [UI 范式示范](ui_creative_arsenal.md)。

## 职责

先写职责，再谈曲线：

- 回答用户动作：打开、展开、确认、撤销时，什么状态被改变了
- 全页最多一个编排点；其余界面静默
- 高频操作（表格翻页、后台切换、阅读滚动）不重播长入场
- 可被打断：连续操作不必等动画结束
- 内容默认可见：动画是渐进增强，脚本失败时正文仍在

## 工程底线

- 只动画 `transform` 与 `opacity`；不对 `width` / `height` / `top` / `left` / `margin` 做过渡
- 写明具体属性，不用 `transition: all`
- 循环动画隔离在叶子节点，不拖动整页重绘
- 必须提供 `@media (prefers-reduced-motion: reduce)`：位移类到最终位置，循环停止，交错延迟取消，加载改为文字或静态条

## 观察

必须在真实运行里看到开始、中间、结束。计算样式和单帧截图不能证明动效成立。确认不抢焦点、不挡内容、可打断。未观察标未验证。

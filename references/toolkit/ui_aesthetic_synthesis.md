# UI 审美综合：从内容 DNA 到不可替代的形式

用于完整新 UI、明显改版，或现有方向只剩“高级、简约、现代、科技感”等抽象词时。它位于体验模型之后、视觉与交互构成之前：不负责给页面换皮，而负责把当前内容与情境转成可实施、可质疑、可验证的审美假设。

局部修复、已有设计系统内的常规页面，若不会改变整体表达，可只写一句沿用依据后跳过完整协议。不要为了表现创造力强行推翻成熟模式。

## 一、提取 Content DNA

Content DNA 不是风格标签，而是当前作品不能被任意替换的内容关系。只记录会改变设计的部分：

- **主角**：人首先需要理解、判断或操作的对象是什么。
- **处境**：谁在什么时刻、带着怎样的预期或压力进入。
- **核心关系**：比较、累积、转变、探索、协作、照料、证明或其他真实关系。
- **内在张力**：两种同时成立而不能被粗暴消解的力量，例如严谨与呼吸、熟悉与陌生、速度与慎重。
- **时间与密度**：体验是一次聚焦、持续工作、线性阅读，还是反复扫描与返回。
- **可信依据**：可信度来自来源、材料、过程、人物、数据还是可操作反馈。
- **不可替代特征**：若换成另一个项目就不再成立的内容、行为或品牌事实。

用一至三句话收束，不写一串气质形容词。例如：“这不是展示更多观测数据，而是让城市居民在短暂夜行中重新学会留意；路径应从日常熟悉感逐步进入陌生细节，同时让时间、地点和安全信息始终可靠可得。”

材料不足时保留 unknown 或提出最小假设；不能用虚构品牌故事补全 DNA。

## 二、发现核心审美张力

从 Content DNA 中选择一个会影响多项形式决定的核心张力。张力不是二选一，而是作品需要同时维持的关系。检查它能否预测至少三类选择，例如信息层级、空间节奏、图文关系、颜色面积、交互反馈或运动时间；若只能换一个颜色或字体，它还不是有效张力。

不要把每件作品都推向“克制 × 张力”“秩序 × 打破秩序”。如果内容本身需要稳定、重复或安静，差异可以来自精确的组织关系，而不必制造戏剧冲突。

## 三、形成结构假设

先说明体验如何展开，再谈外观。结构假设至少回答：

1. 第一眼／第一步由什么承担。
2. 之后的信息或动作如何推进。
3. 哪里需要停顿、比较、回看或恢复。
4. 核心张力怎样进入布局、内容顺序或状态变化。
5. 哪一部分沿用用户熟悉的模式，哪一部分因当前内容而改变。

方向仍开放、不同结构会改变体验时，生成少量真正不同的假设并比较其收益、代价和失效条件。只换色、换字体或换主图不算不同方向。方向已明确时直接深化，不固定方案数量，也不为形式上的确认中断用户。

## 四、定义 Distinctive Relation 与 Restraint Rule

- **Distinctive Relation｜辨识关系**：一个能被感知、能追溯到当前内容的关键形式关系。它可以是阅读路径、比较方式、图文结合、状态转变、密度、对齐或反馈品质，不必表现成醒目的视觉动作。
- **Restraint Rule｜克制规则**：明确哪些元素不参与竞争，以及主要表达通道在哪里停止，避免整页同时炫技。

例如：关键洞察沿阅读路径逐步显现；其余操作反馈保持即时、短促且不使用长入场。找不到有依据的辨识关系时明确写 `none`，不为证明原创而制造噱头；克制规则不能以降低必要信息可读性为代价。

## 五、适配品牌与 Taste Memory

先从当前品牌和项目体系读取已有证据，再按授权检索与当前场景匹配的个人资产。记录：

- 采用了哪条品牌事实、已确认偏好或有证据的候选系统。
- 它在当前任务中如何被调整，而不是直接复刻。
- 哪些内容只是 AI 推断或仍未知。
- 哪些个人偏好因任务、事实、可用性或伦理边界而没有采用。

个人品味帮助选择，不覆盖主要任务和真实内容；公共案例只能提供问题、关系和失效条件，不能成为页面骨架。

## 六、写成可执行的审美假设

完整新作可在内部使用以下最小结构；不必逐项向用户展示：

```text
Content DNA：主角、处境、核心关系、不可替代特征
Core Tension：需要同时维持的两种力量
Palette Hypothesis：从客体与品牌来的面积与色温关系；无依据时保持 unknown，不套命名皮肤
Perceptual Sequence：第一眼／下一步／停顿或返回
Structural Hypothesis：关系怎样进入布局与状态
Distinctive Relation：本作品有依据的辨识关系；没有则为 none
Restraint Rule：哪些通道保持安静，表达在哪里停止
Taste / Brand Adaptation：采用的证据、调整与未采用项
Trade-off：为了什么牺牲什么；在哪些条件下会失败
Encounter Evidence：用哪个关键切片、尺寸、路径和反事实测试验证
```

只保留会改变设计决定的字段，不为完成仪式补齐术语。有效假设必须能预测多项设计选择，也允许被成品推翻。若最终只能得到“使用大字、留白和高级配色”，回到 Content DNA。

## 七、先制作 Critical Slice

在铺开整套界面前，先用真实内容制作最能暴露方向问题的关键切片：例如首屏与下一段关系、核心任务加失败恢复、高密度对象列表，或移动端最困难页面。选择取决于页面职责，不默认首屏就是最佳验证对象。

关键切片至少验证：内容层级、核心张力、克制规则、一个困难状态，以及已提出的辨识关系；辨识关系为 none 时，验证成熟模式为何正好适合任务。方向成立后再扩展；小改或成熟设计系统中的常规页面无需额外样稿。

## 八、差异化不是换皮

定稿前执行五项检查：

1. **归因测试**：关键形式能否指回当前内容、任务或品牌事实。
2. **替换测试**：隐藏名称、替换主图或换成另一个项目后，结构是否仍可无损套用。
3. **三层同质化检查**：分别比较表层语言、结构语法和情绪基调，而不只检查颜色。
4. **近期作品比较**：重复是品牌连续性、成熟交互模式，还是未经思考的默认答案。
5. **明暗情境检查**：深色是否由使用情境（夜间、暗光、发光画布、长时专注）决定，还是逃避浅色层次的默认。日间生产力、阅读或消费界面，浅色往往更适切；例外要写清。

若表达仍通用，优先重新推导观看／操作关系，不靠随机不对称、换色、纹理或动效制造差异。后台和高频工具的辨识度可以来自密度、对齐、对象关系与反馈品质；熟悉和高效本身可以是正确选择。

## 九、允许多种成立的美

Muse 不把所有方向收敛到同一种安静、克制和精致。严密、粗粝、繁复、朴素、戏剧性或日常感都可能成立；判断它们是否来自当前作品，并在真实使用中同时守住设计适切与伦理完整。

有意的不对称、尺度突变、节奏中断、手工痕迹或不规则留白可以保留，但要说明它承载的关系，并在真实尺寸和任务路径中复看。无法说明作用的“个性”只是噪声。

# UI 负向底线与反 AI 偏见守则 (Negative Constraints & Anti-AI Floors)

可在成品上直接证伪的底线。它融合了品味系统与专业前端工程实践的反平庸守则。过不了这些，设计适切与工程完整不成立；过了也不等于美。

## 0. 这些是默认值，不是绝对禁令

**6.0 起，本清单默认生效，但允许有意偏离。** 判断标准不是「有没有违反」，而是「偏离是有意的还是无意的」——底线的全部作用是挡住**无意的** AI 统计惯性，而不是禁止有意的形式选择。

偏离的两种正当做法：

1. **修** —— 大多数情况。偏离往往是无意的，改掉即可。
2. **声明** —— 当某项确实是该作品的形式语言时，在文件顶部留下带理由的可见声明：

   `<!-- muse:allow pure-black: 瑞士黑白排印以纯黑为骨架色，这是本母体的形式语言 -->`

声明只在**本文件内**生效，必须带理由，并会被 `lint_ui.js` 与 `audit.js` 原样列出。**偏离被允许，但不被隐藏**——这是它和「无视规则」的唯一区别。库内现存的正当声明会以「已声明的例外」列出，可以作为写法参考。

**不可声明的部分**（它们不是审美偏好，声明无效）：

- 事实与来源的真实性（§2）
- 无障碍底线：对比度、键盘焦点环、触控靶区（§4）
- 内容账本中标记为 unknown 的项

## 1. 形式与反 AI 偏见 (Anti-AI Tells)

以下为模型最易犯的统计偷懒惯性，**默认禁止**；确属母体形式语言的偏离须按 §0 声明：

| 严厉禁止的错误模式 | 背后原因与失效表现 | 正确工程实现 |
|---|---|---|
| **🚫 封杀圆角割裂色条**<br>（`border-left: 3px solid` 贴在圆角容器上） | 几何曲率断裂冲突，造成极其廉价的模板拼贴感 | **✅ 全包围 1px 微透细线 + 柔和背景色阶 + 精致排版符号**（如 `✦`） |
| **🚫 封杀紫蓝霓虹大渐变**<br>（The Lila Ban / AI Purple-Blue Glow） | 滥用高频高饱和紫蓝霓虹发光球冒充“科技感”，产生巨大视觉噪音 | **✅ 绝对中性底色（Zinc/Slate）+ 单一高对比强调色**（琥珀金/薄荷绿，面积 $< 10\%$） |
| **🚫 封杀死黑 `#000` 与刺眼死白 `#FFF`** | 缺乏现实物理光影温润感，引发严重视觉疲劳 | **✅ 使用有温度的羊皮纸暖白 `#FBF9F5` 与深曜石 `#0E1116`** |
| **🚫 封杀高密度下的嵌套卡片**<br>（Anti-Card Overuse） | 当 `VISUAL_DENSITY > 7` 时，层层嵌套卡片吞噬空间，造成信息闭塞 | **✅ 使用 1px 细分隔线（`divide-y` / `border-t`）或纯负空间逻辑分层** |
| **🚫 封杀千篇一律的居中大标题**<br>（Anti-Center Bias） | 当 `DESIGN_VARIANCE > 4` 时，默认居中 Hero 显得极度呆板 | **✅ 强制采用左右分屏 (50/50)、左对齐内容+右侧资产或非对称留白** |
| **🚫 封杀 Emoji 充当 UI 功能图标** | 跨平台渲染不可控，破坏专业工具严肃感与排版秩序 | **✅ 统一使用单色描边/填充的专业矢量图标库**（如 Lucide / Phosphor / Radix） |
| **🚫 封杀非模度任意尺寸**<br>（如 `13px`、`17px`、`27px`） | 打破空间比例与模度节奏 | **✅ 严格遵循 $N \times 4\text{px}$ 或 $N \times 8\text{px}$ 模度阶梯** |
| **🚫 封杀横排 3 等分等宽卡片**<br>（NO 3-Column Equal Cards） | 三点等宽是模板化布局的第一特征，视线无主次、信息无张力 | **✅ 改用 2 列错位 Zig-Zag、7:3 黄金分割网格或裸排数据列表** |

## 2. 真实数据与消灭伪造痕迹 (The "Jane Doe" Ban)

> 本节属**不可声明**：伪造数据是事实问题，不是审美偏好。

严禁在界面中填充可预测的 AI 假数据模版，必须根据业务语境生成有机、真实的专业数据：

- ❌ **封杀通用假名**：严禁出现 `John Doe`、`Jane Doe`、`Sarah Chan`、`Jack Su`；
- ❌ **封杀老套初创公司名**：严禁出现 `Acme Corp`、`Nexus`、`SmartFlow` 等 AI 典型假公司；
- ❌ **封杀整数与虚假指标**：严禁出现 `99.99%`、`50%`、`1234567`，必须使用有机且有技术深度的真实业务数据（如 `47.2%`、`+1 (312) 847-1928`、`Attention 稀疏化率`）；
- ❌ **封杀默认抽象头像**：禁止使用粗糙的 SVG “鸡蛋头”头像，必须使用有机质感头像或精致的单色徽章。

## 3. 性能与热路径守则 (Performance Guardrails)

- **动效属性限制**：过渡与动画必须且只能驱动 `transform` 与 `opacity`，严禁修改 `top`、`left`、`width`、`height` 等引发重排（Reflow）的属性。
- **连续光标追踪隔离**：磁力微悬停与 Spotlight 光晕严禁使用 React `useState` 触发渲染热路径，必须使用 Framer Motion `useMotionValue` 或原生 Direct DOM。
- **噪点纹理隔离**：Grain/Noise 纹理必须且只能施加在 `fixed inset-0 pointer-events-none` 独立伪元素上，严禁加在滚动容器上导致 GPU 持续重绘。
- **噪点层不占用高层级**：Grain 固定层用 `isolation: isolate` 建立独立层叠上下文，并以**同级低 `z-index`**（`z-0` / `z-1`）压在内容之下。它的固定性不代表可以占用 `z-50`；下一条纪律对它同样生效，无例外。
- **依赖前置验证**：`import` 任何第三方库（`framer-motion`、`@phosphor-icons/react`）前**必须检查 `package.json`**；未安装时先在代码前给出显式安装命令，不写出无法运行的引用。
- **动效叶子节点隔离**：常驻活体动效必须封装在极小的叶子 Client Component（`'use client'` + `React.memo`）中，**严禁让它触发父级布局组件的 Reflow / Re-render**。
- **Z-Index 纪律**：严禁在普通元素上滥用 `z-50` 或 `z-10`，Z-Index 严格保留给模态窗、固定导航等系统级图层。

## 4. 人体工学与可达性红线

> 本节属**不可声明**：对比度、键盘焦点环、触控靶区是可用性底线，不因艺术意图而豁免。

- **文字对比度**：正文文字对比度必须 $\ge 4.5:1$（WCAG AA），大标题 $\ge 3:1$。
- **移动端全屏视口**：移动端全屏高度必须使用 `min-h-[100dvh]`，禁止使用导致移动浏览器地址栏遮挡的 `h-screen`。
- **正文行长**：正文行宽限制在 `50–75ch`（`max-w-[65ch]`）附近，禁止无节制全屏通栏横拉。**注意这是起点而非常数**：[跨媒介基础](../foundations.md) 明确指出「英文 `ch` 不能当中文字符数」——中文正文的合适行宽需按字号与语言单独推定，母体有依据的偏离按 §0 声明即可。真正不可让的是「无节制通栏」这个现象本身。
- **触控靶心**：移动端可点击靶心强制 `\ge 44 \times 44\text{px}`，为指尖留出误触余量。
- **表单标签**：输入框必须绑定带 `for="..."` 的显式 `<label>`，不以 placeholder 代替标签。
- **主按钮唯一**：严禁同一视窗并列多个 Primary 按钮，否则等于没有主操作。

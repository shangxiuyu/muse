# 图像：主题、构图与表现语言

摄影、写实人物、产品静物、建筑或风景任务同时读取 [摄影工具](photography_tool.md)；海报、封面、编辑版式、字体与色彩系统读取 [视觉语法](../visual_grammar.md)。

先明确图像职责与媒介：产品证据、说明图、品牌插画、摄影、拼贴、绘画或抽象图形。用户要求平面插画时不自动加入真实皮肤、景深或相机型号。

## 构思

1. 主体与动作：谁／什么在发生什么，哪些细节具有内容意义。
2. 构图：视觉重心、主体比例、朝向、裁切、图文空间与最终画幅；根据主体—环境关系选择中心、三分、对角、引导线、框景、留白、重复、开放或封闭构图，不为套公式牺牲已成立的关系。
3. 表现语言：写实、概括、夸张、拼贴、超现实等，保持造型和材质关系自洽。
4. 光色与质感：写实检查光位、光质、色温、接触阴影与材质反射的一致性；插画可用平面色块。纸纹、颗粒、失焦和运动模糊仅在承担叙事职责时使用。
5. 约束：真实提供的品牌、必须保留内容、不能出现内容、文字准确性和交付规格。

用具体关系描述期望，而非堆叠“高级”“8K”。但不要把某个提示词当作跨模型毒词；最终判断来自输出。器材或胶片名仅在相关且准确时使用。

## 执行

调用当前环境可用的生图工具，并遵循其实际参数约定。不要给所有工具传 Midjourney 参数，也不假定模型都支持负向提示。工具或参考图缺失时明确限制。

## 复看

核对主体、动作、构图和要求，检查文字、解剖／结构、裁切和风格一致性。产品证据需要真实来源；概念插画必须如实标注。逐轮优先修最大缺陷，避免每轮同时换主体、光线和风格而丢失判断依据。

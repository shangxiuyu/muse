# 场景与用户心智驱动设计决策树 (Scenario & Persona-Driven Decision Matrix)

本文件指导 AI 根据用户的**真实用户画像、使用心理预期与业务场景**，自适应推导最佳设计手段，严禁生搬硬套死模板。

---

## 1. 用户画像与心智推导三步法 (The Persona & Context Probe)

在接收到任何创作指令时，AI 必须先在内心完成以下 3 项核心推导：

```text
               ┌── [Who]     用户画像是谁？ (高频极客 / 消费大众 / 严谨高管 / 沉浸创作者)
[用户指令输入] ──┼── [Mental]  核心心理预期？ (极致效率防打扰 / 简单清晰怕迷茫 / 权威数据确定性 / 呼吸与美感)
               └── [Context] 场景与交互载体？ (10米演讲大屏 / 多屏密集工作台 / 移动碎片 / 纸质画册)
```

---

## 2. 场景与手段推导矩阵 (Decision Mapping)

### 场景 A：商业决策 / 投资路演 / 董事会汇报
* **用户心理**：注意力稀缺、对数据极度敏感、关注确定性与 ROI。
* **调用构件**：`toolkit/presentation_tool.md` 手法 2（数据与结构型）+ `toolkit/text_narrative_tool.md` 模型 A（BLUF）。
* **UI/拓扑锚点**：预设 `vercel-mono` 或 `stripe-modern`；骨架使用 `Dense Instrument Station` 或 `Bento Grid`。
* **调性标尺**：冷峻严谨、信噪比极高、逻辑骨架清晰。
* **自适应手段**：
  * **排版**：3/4 栏严密网格，核心指标采用大字号等宽数字（Tabular Figures）。
  * **配色**：单色底色（深炭黑或纯白），单一克制的数据高亮色（如深蓝或冷绿），严禁渐变装饰。
  * **文字**：结论前置（BLUF），无修饰词，全是数据指标与因果推导。

---

### 场景 B：产品发布会 / Keynote 演讲 / 品牌宣言
* **用户心理**：需要被情绪感染、处于远距离观看状态、记忆点单一。
* **调用构件**：`toolkit/presentation_tool.md` 手法 1（宣言焦点型）+ `toolkit/text_narrative_tool.md` 模型 B（海明威短句）。
* **UI/拓扑锚点**：对照 `references/archetypes.md` 之【冷峻电影】或【赛博诗意】；UI 优先使用 `Swiss High-Typography`。
* **调性标尺**：极致视觉张力、电影感节奏、单页单焦点。
* **自适应手段**：
  * **排版**：大幅非对称留白，超大字阶标语（字高占屏 1/6 以上），全屏出血大图。
  * **配色**：高对比黑白，配合戏剧性单侧点光源，营造沉浸感。
  * **文字**：海明威式短句，金句提炼，富有思想哲思与张力。

---

### 场景 C：工程工作台 / 开发者工具 / 专业后台 (B 端核心)
* **用户心理**：“别废话，给我效率，一屏看清所有状态，键盘操作优先。” 对视觉噪点零容忍。
* **调用构件**：`toolkit/ui_blueprint_protocol.md` + `toolkit/ui_product_tool.md`（挂载 `linear-dark` 或 `vercel-mono`）+ `toolkit/motion_video_tool.md`（动效锁 Subtle 档 120ms）。
* **UI/拓扑锚点**：对照 `references/archetypes.md` 之【工业功能】；骨架选用 `Split-Screen Console` 或 `Dense Instrument Station`。
* **调性标尺**：极高信息密度（Compact 8px 网格）、状态指示完备、操作直觉无歧义。
* **自适应手段**：
  * **排版**：紧凑 4px/8px 网格，1px 微细边界分割，清晰的状态标签。信息密度优先，留白率下调至 20%-40%。
  * **配色**：低照度暗曜石灰或极简平整灰，语义色（红/黄/绿）仅在状态异常时亮起。
  * **交互**：8 态闭环、全局快捷键提示、零延迟即时响应。

---

### 场景 D：文化人文 / 艺术画册 / 深度特稿 / C 端沉浸产品
* **用户心理**：追求精神沉浸、欣赏细腻质感与思想余味，厌恶粗糙与工业冷感。
* **调用构件**：`toolkit/ui_product_tool.md`（挂载 `apple-editorial` 暖米白）+ `toolkit/text_narrative_tool.md` 模型 B（写实白描）。
* **UI/拓扑锚点**：对照 `references/archetypes.md` 之【人文杂志】或【东方侘寂】；UI 优先使用 `Swiss High-Typography Editorial` 或 `Interactive Timeline Rail`。
* **调性标尺**：典雅考究、图文呼吸感强、自然温润。
* **自适应手段**：
  * **排版**：经典衬线体与无衬线混排，考究的字间距与行高比（1.6-1.8），不对称图文穿插。
  * **配色**：低饱和大地色系、纸张本色质感（Off-white #FBF9F6）、细微颗粒感。
  * **文字**：白描手法，富有思想洞见，句式有长短起伏的音律感。

---

## 3. 未覆盖场景的自适应推导法则 (Fallback Rule)

当任务不落入 A-D 任一标准场景时，直接由用户画像的 3 个维度推导设计系统参数：

1. **受众注意力越稀缺** ➔ 字阶对比越强、单屏焦点越唯一、操作入口越显著；
2. **使用时长越久 / 操作频率越高** ➔ 信息密度越高（Compact）、装饰性光晕越少、组件 8 态越完备；
3. **情绪与品牌目标越重** ➔ 留白与影像占比越大、字阶越大（Spacious）。

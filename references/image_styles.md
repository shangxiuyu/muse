# 生图风格库：15 套表达起点

<!-- muse:genre spec -->

这是 Muse 自带的图像表现资源，随 skill 分发，运行时不依赖 BaoYu 安装、网络或个人品味库。它与 UI 的[视觉母体库](archetypes.md)分开：这里指导笔触、造型、材质与图文表达，页面组件和交互仍由各自媒介处理。

## 按需使用

1. 先沿用用户指定的风格、参考和品牌要求。需要从库中选择时，用下表定位，再只读选中的风格卡；比较方向时再读对应候选。
2. 无明确风格时，根据要解释的关系、期望情绪和观看尺寸选一个起点，简述依据后继续；日常单图不强制让用户先选风格。用户要求库外风格时照常创作，这 15 套不是能力上限。
3. 把信息结构、表现语言与配色分别决定。表中的使用线索帮助联想，不限制题材；同一画风可以表现不同内容，也可按用户要求混合。混合时说明哪套负责主体造型，哪套只提供笔触、材质或色彩。
4. 每张卡提供识别特征与可调参数。用户的改色、改密度、改背景等要求直接进入本次方案，不需要申请风格例外；版式按真实内容组织。
5. 将风格片段与主体动作、对象关系、准确文字、画幅和参考要求合成一份实际提示词。片段本身不是完整任务，卡片里的标签和说明不作为画面文字。
6. 在当前提示词记录中简记所用 ID、选择依据、保留的特征与本次调整；使用自定义参考可记为 custom。依[图像工作流](toolkit/image_visual_tool.md)执行并查看真实结果，不因选了卡片就默认验收通过。

## 相近风格如何分辨

- 手绘知识图强调多个要点之间的图解关系；极简线稿用少量笔画突出单个视觉关系；手写笔记让文字、圈画与纸面成为主体。
- 扁平插画依靠几何造型与色块讲场景；复古波普用粗重分隔、反转对比和纹样形成图形节奏。
- 工程蓝图突出精密线图及节点连接；杂志信息图突出字级、图解、标注之间的编辑组织。
- 丝网版画依靠剪影、分色与套印；剪纸拼贴依靠纸边、叠层和投影；黏土微缩依靠捏塑体块与材料触感。
- 风格可共享颜色或构图。区分看的是造型和媒介特征，不是换一个背景色或名称。

# Taste Memory｜用户品味记忆 (轻量版)

Taste Memory 不是一份固化的“用户风格标签”，而是人与作品真实相遇时的共鸣沉淀。它帮助 AI 了解用户在什么场景下对什么产生过共鸣、哪些是用户原话、哪些是 AI 推断，从而在创作中形成恰当的审美假设。

---

## 核心原则：防过拟合与情境感知

1. **品味源于情境**：用户在研究报告中喜欢“高密度表格”，不代表在落地页中也喜欢；在某次海报中喜欢“留白”，不代表所有页面都要大面积留白。
2. **区分事实与推断**：
   * **用户原话是第一手事实**：哪怕只有一句“这里很舒服”或“太土了”，原话即最有价值的信号。允许原因“未知（说不清）”，绝不为了格式完整而由 AI 凭空捏造因果。
   * **AI 总结只是假设**：从多张素材中归纳的模式属于“待确认假设”，不能擅自当作不可违背的硬规则。
3. **轻写入，强推理**：记录时保持轻量直接，创作时结合当前任务上下文进行就地推理与关系匹配。

---

## 三层个人审美资产

摒弃繁复的状态机流转，将个人品味资产收敛为直觉的 3 层结构：

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 灵感与原话 (Inspirations & Quotes)                         │
│    - 素材链接/截图 + 用户的真实第一手反馈（哪怕仅一句话）     │
├─────────────────────────────────────────────────────────────┤
│ 2. 观察与假设 (Observations & Hypotheses)                    │
│    - AI 从多次反馈中归纳的可迁移倾向（标注为 AI 推断）       │
├─────────────────────────────────────────────────────────────┤
│ 3. 铁律偏好 (Confirmed Rules)                               │
│    - 用户明确指令“以后都这样做/记住这个习惯”的特定情境规则   │
└─────────────────────────────────────────────────────────────┘
```

| 资产层级 | 触发与来源 | 包含内容 | 适用原则 |
|---|---|---|---|
| **1. 灵感与原话** | 用户说“收藏这个”、“喜欢这块排版”、“讨厌这里的颜色” | • 素材来源 (URL/文件)<br>• 用户原话 (保留主观词与情绪)<br>• 涉及对象 (整体/局部/特定交互) | 忠实记录，不擅自补齐因果，不升级为通用规则。 |
| **2. 观察与假设** | AI 观察到多个灵感中的共性规律 | • 提炼的形式关系 (如：排版节奏、色彩层级)<br>• 适用场景与边界 (如：仅限数据看板) | 作为设计建议与复核参考，不强制覆盖新任务。 |
| **3. 铁律偏好** | 用户明确表示“以后研究报告都这样排”、“记住这个背景色” | • 明确规则与场景范围<br>• 例外情况 | 优先尊重，但仍服从当前任务的特殊硬性要求与可用性底线。 |

## 极简记录格式 (Markdown / YAML)

无需复杂的 JSON 接口与版本链，采用人类与 Agent 均极易阅读与追加的轻量格式：

### 灵感与原话记录 (Inspirations)
```yaml
- id: insp-202609-held-cards
  date: "2026-09-16"
  source: "held/ui_reference.png"
  scope: "移动端健身卡片"
  user_quote: "喜欢这种卡片的微呼吸感和低饱和度，但文字对比度还可以再高一点。"
  target: "卡片间距与阴影"
```

### 观察与假设 (Hypotheses)
```yaml
- hypothesis: "在身心健康类 App 中，倾向于使用柔和大地色（米白/鼠尾草绿）配合细边框，弱化强烈阴影。"
  based_on: ["insp-202609-held-cards", "insp-202608-yoga-deck"]
  status: "inferred_by_ai"
  applicable_to: "健康/瑜伽/冥想类产品界面"
```

### 铁律偏好 (Confirmed Rules)
```yaml
- rule: "所有深色模式设计，主背景禁止纯黑 (#000000)，统一采用微冷深灰 (#0D1117 或 #12141A)。"
  scope: "Web / App 界面深色主题"
  source: "用户在 2026-09 对话中明确指定"
  status: "confirmed"
```

## 创作时的调用流程

在进入具体创作（UI / 文本 / 演示 / 图像）时，按以下轻量三步应用品味记忆：

1. **检索匹配**：检查是否有适用于当前场景的 **铁律偏好** 与 **观察假设**；
2. **就地融合**：将品味假设与当前任务的业务事实、媒介限制结合，形成本任务的审美方案；
3. **保留边界**：若个人偏好与当前可用性（如可访问性对比度）冲突，以可用性与实际任务要求为准，并向用户说明权衡。

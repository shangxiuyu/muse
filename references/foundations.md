# 跨媒介审美基础：从可观察关系作判断

本文件是 [Aesthetic Reasoning](aesthetic_intelligence.md) 的媒介基础层，用于把审美假设落实为构图、排版、色彩、图像、运动与声音的具体判断。先定位内容、情境、感知秩序与张力，再查本文件；不要从字号、色板或动效参数反推概念。以下数值都只是试排起点，需要由内容、最终载体与真实相遇验证。

## 内容、形式与感受

找出内容中特有的关系：对比、因果、时间、集合、层次、连接或单一陈述。结构应让这条关系更易感知。“高级、现代、干净”尚未形成概念。

将期望感受译成可观察行为。“可信”意味着来源可追溯、尺度不误导、操作可预期；“轻快”可用节奏和留白变化，不必降低文字对比度；“活泼”可用鲜色、裁切和语气，不必每个对象跳动。

## 构图：注意力的组织

- **视觉重量**由面积、对比、位置、形状复杂度和内容共同决定。人脸、小块鲜色或孤立对象可能比大面积灰底更抢眼。
- **平衡**可以对称、非对称或有意不稳定。单一仪式性主张适合轴线；多项扫描需要稳定对齐；表达冲突可以偏置，但阅读入口仍须可辨。
- **层级**决定先后和重要性。明确入口、证据、行动的关系；复杂工作台可以有局部焦点，不必全页只有一个可见重点。
- **节奏**来自重复和变化。重复建立预期，变化标记差异；不要每块都独特，也不要把不同内容塞进同形卡片。
- **负空间**用于分组、突出或停顿。比较组内与组间距离，再决定总留白；没有通用的“高级留白百分比”。

诊断：缩小或模糊观看，首先看见哪里？回到实际尺寸，视觉顺序是否符合任务顺序？灰度观察辅助检查明度层级，不能代替彩色情境。

## 排版：可读性与性格

| 决策 | 看什么 | 常见误用与修正 |
|---|---|---|
| 字体 | 文体、字形性格、语言覆盖、载体 | 衬线不自动等于人文，科技产品不必全部等宽；检查真实中文、数字和标点 |
| 层级 | 内容组织与观看距离 | 400/500 不足以区分时，使用尺寸、位置或更强字重；不要把次要信息淡到难读 |
| 行宽／行高 | 字体、语言、字号、阅读量 | 英文 ch 不能当中文字符数；长行需要适当行间距，窄列避免碎裂换行 |
| 字距 | 字形和字号 | 拉丁展示大字可试负字距；同值不机械应用于中文正文和复杂字形 |
| 强调 | 什么需要被找见 | 加粗、颜色、位置各有职责，不必对一个词叠加所有强调 |
| 对齐 | 扫描、比较或仪式阅读 | 多行居中入口参差，短标题居中可稳定有力；数字按位对齐利于比较 |

中文正文可从 1.5–1.8 行高、英文正文从约 45–75 字符行宽试排，仅作为起点。检查短／长标题、真实段落、混排、文字放大和移动端。移动端不能只缩小桌面排版。

## 色彩：明度、面积和语义

先确定背景与有效文字的明度关系，再分配品牌与强调色。记录颜色职责：内容、操作、状态、分类、装饰。多个颜色不必然杂乱；相同角色的稳定性和面积分配更重要。品牌色不能占用错误色等语义而造成歧义。

饱和度结合面积判断。小块鲜色可定位，大面积鲜色可表达品牌；图像色彩也参与全页。实际背景上检查文字，不凭独立色卡判断。

普通有效文字通常至少需要 4.5:1，大型文字为 3:1；禁用与纯装饰有例外。次级标签不自动豁免。状态配合文字或形状，不能只靠颜色。[W3C 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

诊断：去掉品牌色，信息仍能理解吗？恢复颜色后增强了什么？检查真实图片背景、主题切换和状态。对比度不等于完整审美评分。

## 图像、材质与图文关系

先选图像职责：证据、解释、情绪、人物识别或叙事。装饰图可成立，但不能伪装成产品证据。

- 裁切保留重要手势、视线和环境；让画面朝向与文字入口形成关系。
- 写实作品检查光线、尺度、透视；插画、拼贴、超现实检查自身造型规则的一致性。
- 器材名、颗粒和纸纹是可选手段，不能替代主体选择或保证质感。
- 阴影、边框、模糊可用于层次、焦点和气氛；判断职责，避免无功能叠加。

诊断：移除图像会损失什么信息或必要感受？若换任意图库图都成立，可能尚未与内容建立联系。

## 时间与运动

运动解释变化、反馈、注意力或情绪。把大胆花在一个地方（Spend your boldness in one place），全页聚焦单一编排时刻，杜绝散落的区块淡入与卡片悬停；高频操作优先即时响应；品牌叙事允许停留；静态阅读可以不加装饰动画。

距离、速度、加速度、延迟和重复共同决定感受。120ms 不是通用标准，贝塞尔曲线不等于真实弹簧模拟，推崇具备实体分量感的物理弹簧阻尼与 Bento 活体原型。不要在频繁操作时重播长入场，动效随时可被打断。减弱动效下保留等价信息，内容不能依赖动画才出现。详见 [时间与运动规范](toolkit/motion_tool.md) 与 [W3C 动画说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)。

## 一致性与有意变化

相同角色保持相同表现，真正不同的角色允许变化。先安排结构、色彩、字体、图像和运动的职责，再保留与内容相关的识别特征。不要同时把所有表达通道推到最大。

改动前说清要改善哪种关系，之后用真实内容和关键状态验证。装饰不损失意义时可删；承载品牌或情绪时可保留。

## 条件化规则卡

新增规则使用：**目的 → 适用条件 → 可观察做法 → 不适用情境 → 代价 → 验证方法**。

例：为了比较效率，同单位多行指标使用对齐数值列；单一仪式数字可以居中；紧凑表格牺牲叙事节奏；用长值和不同位数检查。不能泛化为所有内容必须左对齐。

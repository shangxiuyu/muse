用户已选择第一版「纸间创作室」。按 direct_edit 模式删除其他两个方向及比较入口；保留原版结构，主题色改为品牌图标暖黄，新增同一布局下的浅色、深色和跟随系统外观。

- 用户提供：Muse 驱动，只产出前端 UI、PPT、文案、图片；通过聊天开始和迭代。
- 已核对：本仓库 Muse 6.0 的审美推理、媒介适配、品味记忆边界。
- 已确认：用户选择暖黄色底的手绘「灵感小脑袋」为 Muse 图标，用于网站品牌位置、创作伙伴头像与浏览器图标。
- 已确认：沿用第一版纸感排版，主题色采用图标的暖黄。图库均为明确标记的原创示例，无虚构客户或指标。
- 当前授权：在已确认的界面上接入 Pi Agent 后端，真实生成、连续修改、版本与会话落盘；模型通过服务端环境配置。账号、付费、多用户与公网部署另行实施。

## 用户思维与心流
用户带着模糊想法进入，不想先学设计术语。第一秒看到“好想法，值得好作品”，随后选择媒介、输入想法。生成后对话留在左侧，作品在右侧，反馈能直接关联产物。错误保留输入并提供重试。作品和品味保存在本机工作空间，仅发送当前任务、当前对话、所选参考和适用的用户已确认偏好。

## 审美假设
- Content DNA：同一想法通过四种媒介变成可带走的作品；创作对象应比聊天记录更显著。
- 核心张力：创作的开放感与工具的确定性。
- 母体：Writer’s Atelier 的纸张层次和编辑感，搭配品牌暖黄的文具感；不照搬母体版式。
- 辨识关系：首页四张不同媒介的编辑小样与四个入口互相对应；进入创作后，作品预览取代灵感陈列。
- 克制规则：无循环装饰动效、无指标墙、无营销横幅，主按钮每个任务区只有一个。
- 取舍：首屏通过创作邀请表达品牌，品牌故事退到“关于 Muse”；没有单独堆砌营销首页。
- 个人资产：已有学习目录相关 system 的范围与本产品不同，不作为已确认偏好套用；不写入用户私人品味库。

## 设计系统
- Dials：结构偏离度 5 / 动效 2 / 密度 4。
- 浅色：Canvas #FAF9F6；Sidebar #F3F1EB；Surface #FFFFFF；Ink #29271F；Muted #706859；Line #E4DFD4。
- 品牌 Accent #F9C93C，来自用户确认图标最常见的黄色像素；主按钮搭配 #30270E 深色字。浅底强调文字用 #745713，黄色用于底色、选中背景与划线，避免黄字在浅底上不可读。
- 深色：Canvas #1D1C19；Sidebar #181714；Surface #27251F；Ink #F2EEE4；Muted #B2A995；Accent ink #F9D366。作品本身的网页、幻灯片、插画色板不随工具外观变化。
- 品牌图标：保留用户认可的暖黄底、粗黑手绘线条与米白脸颊。原图位于 `../output/imagegen/muse-icon-handdrawn.png`，网页使用 `assets/muse-icon-256.png`；浏览器与主屏幕图标提供 32/64/180px 版本。品牌图片设置明确尺寸，旁有名称时作为装饰避免重复朗读。
- 纸张和墨水为色板依据。白色只用于有限面积的输入纸面和预览，不作为刺眼全屏底色。
- 正文：系统 sans + PingFang SC；品牌与展示：Georgia + Songti SC，中文零字距，正文行长有限。
- 间距以 4/8 为基线；圆角 8/12/16；轻微向下的自然阴影；普通界面深度不超过三层。
- 明确例外：中文工具文字 13/14/15px 用于信息层级；1px 边线与光学校正不受空间模度约束。母体的“禁底部聊天框”不适用于用户明确要求的聊天创作主流程；聊天框在布局内，不遮挡内容。

顶部工作空间栏已移除，桌面对话与预览占满视口高度。外观、模型连接状态、备份与“认识 Muse”集中到左下角“工作空间设置”；展开导航时，个人空间下方显示连接状态。手机端保留独立导航按钮，工作台内与对话/预览标签共用一行。

## 外观行为
- Skill 安装入口按用户标注移到首页创作类型右侧，与输入框右边缘对齐；侧栏移除原入口。采用 60px 高的纸质卡签，品牌图标前后两层轻微错角，文字为「安装 Muse Skill / 把好品味，带到你的 AI 工具」，以虚线分隔末尾箭头。背景与细边框沿用明暗主题，暖黄集中在品牌图标和交互反馈；悬停时纸片轻微展开、箭头右移，减少动态偏好时保持静止。内容区不足 680px 时，卡签在创作类型上方独占一行，整块可点击。点击沿用安装弹窗，支持五种指定工具及「其他 AI」、复制命令和 AI 安装请求；「其他 AI」保留命令行工具选择，AI 安装请求先检查当前工具的支持情况；保留手动复制回退、关闭后焦点恢复及未发送输入。
- 图片风格入口：图片模式下将「添加参考」替换为「图片风格」，独立于 UI、文案与 PPT 的参考菜单。采用宽 248px 的小卡片菜单，15 个选项各带缩略图；鼠标悬停或键盘聚焦时，菜单旁自动展示宽 344px 的大图、名称与画法特征。悬停不改变选择，点击整行才选用并收起，显示带缩略图的可移除标签。保留「随内容判断」选项，不强迫选风格；不打开全屏或模态画廊。
- 本次选图不重建输入框或作品预览。图片风格随每次对话和作品版本保存，重开时恢复，新建时清空；失败、停止与重试保留本轮选择。前后端共用固定风格 ID，模型获取被选风格的完整规范，不把示例主题当作生成要求，不写入长期品味。

- 独立保存外观选择，刷新后恢复；系统模式实时响应系统变化。首屏绘制前确定明暗，减少闪白。
- 切换只更新主题变量，不重建对话、输入、品味表单或作品预览，保留未发送内容、焦点与当前 PPT 页码。
- 旧比较链接统一打开已选版本，作品及品味数据保留。删除替代方向的实现、截图和比较契约。

## 运动与反馈
- 用户要求增强交互动效，继续第一版暖黄纸感方向。职责为状态反馈与空间连续性；不在静止界面播放装饰循环。
- 主曲线 cubic-bezier(.22,1,.36,1)；按压与退场 160–180ms，控件切换 240–320ms，导航与作品入场 360–420ms。单页入场是唯一编排点，后续输入不重播整页。
- 首页内容轻微错峰进入；媒介、筛选与预览标签的选中底色滑动；卡片抬升、快捷建议箭头和发送按钮响应悬停/按压，首次有内容时发送键轻弹。
- 桌面导航用 FLIP 位移与独立背景缩放衔接两种宽度，实际布局只改一次，保留输入和 iframe。手机抽屉直接切换 DOM 状态，滑入/滑出时不重建页面；关闭时设为 inert 避免键盘落入屏外。
- 弹窗带缩放淡入和短退场，退出完毕恢复焦点；内容到达后消息与作品轻入场；PPT 根据翻页方向移动，iframe 等加载后再进入。
- 深浅主题通过浏览器支持的 View Transition 交叉淡化，旧浏览器直接切换；快速重复点击会跳过旧过渡，以最后选择为准。
- 循环仅用于进行中的生成反馈，使用纸面骨架、停止按钮转环和等待点，不表示虚构的完成百分比。完成或取消即停止。
- 仅动画 transform / opacity，不使用 transition: all 或宽高过渡。系统减少动态效果时跳过位移、取消延迟和循环，所有操作仍执行；运行中切换该偏好会直接完成动效。

## 组件与状态
- 核心输入：有 label；Enter 发送，Shift+Enter 换行，中文输入法组合期间不发送。
- 按钮：默认/hover/active/focus-visible/loading/disabled/error；空输入禁用发送；移动触控不小于 44px。
- 预览：隔离 iframe 执行 UI 样稿；文案纯文本渲染；图片为原创 SVG；PPT 可翻页并导出 Web Deck，本轮不提供 .pptx。
- 导航：创作空间、我的作品、灵感画廊、品味记忆。作品可搜索、重开、重命名、下载与删除。
- 品味：用户明确填写“以后在此媒介中……”并保存；不把一次选择或点赞自动提升为偏好，可删除。
- AI：以 Pi SDK 执行真实工具调用。画廊仍为样稿；提交后显示真实进度，可取消、重连和重试，不以样稿兜底。网页与 SVG 使用隔离预览，演示为 HTML Web Deck；像素图像需要单独的图像模型配置。

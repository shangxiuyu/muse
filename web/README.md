# Muse Studio 创作工作台

按照本仓库 Muse 6.0 skill 制作的创作工作台。现已接入 Pi Agent 后端，支持真实生成、连续修改、版本保存与会话恢复。部署与模型配置参见 [后端说明](../server/README.md)。

从仓库根目录运行 `npm run dev`，打开 http://127.0.0.1:4173。后端需要 Node.js 22.19+；先执行 `npm ci --ignore-scripts`。静态文件也可单独预览，但保存与生成需要后端服务。

保留用户选定的第一版纸感布局，主题色为图标暖黄 #F9C93C。移除顶部工作空间栏，创作工作台占满可用高度；外观、模型连接状态、备份与“认识 Muse”统一收进左下角“工作空间设置”。支持浅色 / 深色 / 跟随系统，外观选择单独保存在 `muse-color-mode`，刷新后生效，系统外观变化实时跟随。切换外观保留当前输入、表单、作品版本与 PPT 页码。手机端由左上角独立导航按钮打开抽屉，再访问底部设置。

公共页脚提供「Muse 官网」直达入口，工作空间设置中的「认识 Muse」也可访问[官网](http://47.93.187.177:3404/)。链接在新标签页打开，保留当前创作页面。

首页创作类型右侧提供「安装 Muse Skill」卡签入口，品牌图标、纸张叠层、虚线分隔和箭头呼应纸间创作室；窄屏时移到创作类型上方，整行可点击。侧栏不再放置安装入口。安装弹窗支持 Codex、Claude Code、Cursor、Antigravity、Windsurf 与「其他 AI」。选择「其他 AI」时提供可交互选择工具的通用命令，复制给 AI 的请求会先确认当前工具是否支持 Skill 及其导入方式；其他五项可一键复制对应的全局安装命令，或复制安装请求交给 AI 工具执行；命令使用 [Skills CLI](https://github.com/vercel-labs/skills) 从 Muse 公开仓库安装。运行需要 Node.js 与 Git；页面只提供安装内容，不直接操作访客电脑或后端的技能目录。HTTP 环境与剪贴板权限受限时会尝试兼容复制，失败则显示可手动选中的完整内容。实现位于 `lib/skill-install.js` 与 `skill-install.css`。

已实现：创作首页、四媒介切换、对话与隔离作品预览、源内容、版本切换、PPT 翻页、作品搜索/重命名/删除、内置母体参考选择、品味记忆、工作空间备份、响应式导航及键盘操作。灵感画廊内置 12 套通过 Muse 6.0 引擎生成的完整样板，网页 6 套，演示、文案与图片各 2 套；提交需求后调用已配置的模型，成功作品标为 AI 创作，失败不会回退到样稿。

品味记忆支持从本机 Muse skill 导入：默认定位 `~/Documents/Muse`，设置 `MUSE_VAULT_DIR` 时使用指定目录。点击「从本机 Muse 导入」只读取该目录的 `personal_dna.yaml` 与 `personal_taboos.yaml`；也可通过「选择文件」或拖放导入 YAML / JSON（包含 `preferences`、`taboos`，或工作空间备份的 `memories` 列表）。支持多选，单个文件限 256 KB。先预览已确认的偏好，保留场景、原因与例外，可逐条调整适用作品、取消勾选，再保存到当前工作空间。候选与不完整记录会提示跳过；重复内容自动合并；原文件保持不变，不做持续同步，也不把审美资产库中的收藏和推断转成已确认偏好。

“添加参考”在按钮旁展开紧凑列表，视觉参考显示配色、中文名称与选中标记，文案参考显示文字图标、名称、适用场景与选中标记。网页 UI 提供 10 个全端母体；文案提供独立的 [8 类文案参考](../references/text_styles.md)：清晰说明、温和同行、鲜明观点、故事叙述、轻快分享、产品推介、极简短句、专业汇报；PPT 提供 Muse [演示流派库](../references/toolkit/presentation/archetypes.md)中的 5 个参考：商务咨询、燕麦刊物、科技发布、职场研报、积木波普。点击整行直接选用，列表自动收起；支持点击外部、Esc 关闭以及方向键选择，窄屏自动调整位置。网页 UI 菜单在鼠标悬停或键盘聚焦时，在右侧展示对应的示例截图、风格说明与来源；浏览不改变已选参考，点击才选用。窄屏与触屏先点选项预览，再点“选用此风格”确认。图片来源见[截图记录](assets/archetypes/README.md)。文案菜单以原创例句、表达特点与信息推进方式预览文风，手机先预览，再点“选用此文风”确认；默认随内容判断。单选后可从输入框中更换或移除，切换创作类型分别保留各自选择，继续创作和重开作品沿用已提交的参考，新创作清空。标识保存在对应消息、作品与版本中，后端提供所选规范和版式方法入口；演示只读取所选流派章节与中文排版规则，不把风格当成固定版式，不自动写入品味记忆。旧会话的全端母体与文本附件仍可查看；旧文案的视觉母体保留在历史中，重开及重试时不带入新的文案任务，不再提供本地文件上传入口。

导出：预览区「导出」可下载当前版本的 ZIP 源文件包，包含作品文件、原始内容、设计系统样式与关联规范。网页保留 HTML / CSS / JavaScript；演示保留逐页 HTML、结构化内容和讲者备注；文案为 Markdown；图片保留原始 SVG、PNG、JPEG 或 WebP。设计系统包含实际样式、行内样式、颜色与字体等静态清单，所选内置规范从本机服务读取。没有关联规范的作品可离线打包；规范读取失败时提示重试，不提供缺失规范的包。不会导出内部会话或工作空间偏好，也不会下载外部资源；位图不虚构可编辑图层。

「仅下载作品文件」保留原有单文件导出：网页 HTML、支持键盘与全屏的 HTML Web Deck、Markdown 或原始图片。当前未提供 .pptx 输出。作品、偏好与 Pi 会话保存在服务端本机工作空间，最多 30 件作品，每件 20 个版本。首次连接会迁移旧浏览器作品；创作时将当前需求、所选参考和适用偏好发送给已配置的模型。

文案正文在右侧内容区预览，可切换原文、复制和导出 Markdown。对于尚无作品版本、但已在历史对话中交付的文案，前端会保守识别创作请求与成稿，直接展示已有正文，不修改原始对话；开场介绍和明确标注的创作说明不进入正文。新生成文案要求提交作品；模型遗漏提交时，后端对可识别的完整成稿补做格式检查并保存版本。普通问候、澄清、失败或中断的输出不因此新增版本。

代码职责：`app.js` 管理视图与状态；`styles.css` 维护明暗设计系统与断点；`lib/appearance-init.js` 在首屏绘制前应用主题，`lib/appearance.js` 管理外观切换；`lib/artifacts.js` 提供原创示例和预览隔离；`lib/data.js` 维护媒介与灵感；`lib/icons.js` 提供统一线性图标与 Muse 品牌图片。`dev-server.mjs` 仅为本地静态预览服务，不是生产后端。

品牌图标采用用户确认的暖黄底手绘小脑袋，[设计与提示词](../output/imagegen/muse-icon-handdrawn-prompt.md)。网页资源位于 `assets/muse-icon-256.png`，并提供 32/64px 浏览器图标与 180px 主屏幕图标。原始图片保存在 `output/imagegen/muse-icon-handdrawn.png`，所有网页尺寸均由该图等比缩小。

设计过程归档：[花瓣 M](../output/imagegen/muse-icon-v1-prompt.md)、[感知之花](../output/imagegen/muse-icon-eye-flower-prompt.md)、[缪斯侧影](../output/imagegen/muse-icon-profile-prompt.md)，这些提案未用于网站。

参阅[设计契约](DESIGN.md)与[前端验收记录](QA.md)。

交互动效由 `lib/motion.js` 和 `motion.css` 维护，无新增依赖。覆盖页面入场、选中底色滑动、导航折叠与移动抽屉、弹窗、作品/消息到达、PPT 翻页、生成等待反馈和明暗过渡。动效可被连续操作打断；系统减少动态效果时回到即时反馈。

后端接入：`submitPrompt()` 创建服务端生成任务，通过事件流接收真实进度与回复增量。文字在对话正文中流式排版，支持标题、列表、强调、引用和代码块；收到半截代码时仍按安全文本显示。仅在用户位于底部时自动跟随新文字，上翻阅读和最终完成均保留滚动位置。断线重连获取完整进度，刷新后恢复会话，选中旧版本可继续分支修改。模型凭证保留在服务端，品味只在适用媒介上下文内使用。当前为本机个人版，账号、计费与多用户部署尚未实现。

图片风格示意图的来源与替换方法见 [图片风格预览](assets/image-styles/README.md)。

PPT 参考菜单支持悬停和键盘聚焦预览：旁边展示对应母版的 16:9 演示样张，点击选项才应用参考。预览优先放在右侧，空间不足时调整到左侧；窄屏在列表上方展示。5 张本地图片及可重现的 HTML 源码见 [PPT 参考样张](assets/presentation-styles/README.md)。


「我的作品」采用真实预览的作品架，支持带数量的媒介筛选、即时搜索、最近/最早编辑及名称排序、卡片与列表切换。网页与 PPT 缩略预览不运行作品脚本，原始作品仍可打开继续创作。闲聊、未产出项目和样板示例不进入作品列表或最近创作；文案缩略图支持从已完成对话恢复正文。相关实现位于 `lib/collection.js` 与 `collection.css`。

精选样板由 `lib/gallery.js`、`lib/data.js` 与 `lib/samples/muse-generated.js` 维护：首页展示四种媒介各一份精选，画廊展示全部 12 份并按媒介筛选。网页包含生活品牌、设计工作室、阅读工作台、器物商店、山居旅宿和设计艺术周；两份演示各含六页独立排版及讲者备注，两套文案各含五组传播内容，图片为可离线导出的 SVG。封面使用实际成品的本地截图；文字封面节选实际正文，不依赖外部图片与字体。打开时保存到工作空间，同一版本的样板再次打开会恢复已有副本；标识包含成品校验值，新版本保留旧副本及用户修改。内置内容不计作用户现场生成的 AI 作品，继续对话修改需配置模型。

每套原始需求、Muse 工具步骤、模型信息和原件保存在 `output/gallery-muse/<id>/`。独立验收修复保存在 `reviewed-artifact.json` 与 `review.json`，不覆盖 Muse 原件；两版均有 SHA-256 校验。`scripts/publish-gallery.mjs` 校验创作与修订记录后打包前端目录，`scripts/preview-gallery.mjs` 输出最终预览。生成命令为 `node scripts/generate-gallery.mjs <id...>`，会使用已配置的模型；不会在启动或测试时自动调用。验收记录见 `output/gallery-muse/ACCEPTANCE.md`。

# PPT 参考样张

5 张图片均为 Muse 原创 HTML 演示页的真实浏览器截图，尺寸为 1280 × 720。配色、字体与视觉特征对应已有的[演示流派规范](../../../references/toolkit/presentation/archetypes.md)，示例文字仅用于展示风格。

源码：[演示风格样张](../../examples/presentation-styles.html)。每个样张使用对应的参考 ID，可通过 `?style=ppt_editorial_linen` 等参数单独打开，再对同名元素截图。没有使用外部图片、网络字体或第三方品牌成品。

网页在打开 PPT 参考菜单时预载这 5 张图片，悬停或键盘聚焦选项时切换预览。预览不改变选中值，点击选项才应用参考。右侧空间不足时向左展开，窄屏在列表上方显示，极低可用高度时优先保留可滚动选项。

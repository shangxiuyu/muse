# 范例库 (Exemplars) — 判断标杆，非模仿对象

规则保下限，范例拉上限。本目录收录**用户真心认可**的外部优秀设计拆解，作为 AI 产出时的判断标杆。

> ⚠️ **收录纪律**：只收录用户明确表达认可的案例，AI 禁止自行编造填充。
> 拆解十个平庸案例，只会把平庸编码得更深。第一批案例应由用户亲自挑选。

## 目录结构

```text
exemplars/
├── README.md           # 本文件
├── presentation/       # PPT / Keynote / Deck
├── ui/                 # 网页 / App 界面 / 组件
├── text/               # 文案 / 文章 / 叙事
├── visual/             # 摄影 / 生图 / 视觉风格
└── motion/             # 动效 / 视频 / 剪辑
```

## 标注模板（每个案例一个 .md 文件）

```markdown
# 案例：[名称]（媒介/年份）

**来源**：URL 或出处
**截图/描述**：（用文字精确描述画面，或引用图片路径）

## 为什么好
逐点拆解具体决策——必须是可观察的事实，而非"高级感"这类空词。
例："标题字重 450 而非 600——全页信息密度低，更重字重会让标题
'喊'而不是'说'。"

## 可复用判断
从案例中抽象出的一条可迁移判断（不是参数，是原则）。
例："低密页面用字重克制换'自信感'。"

## 何时不适用
该判断失效的反场景——这栏决定范例是训练数据还是教条。
例："高密度控制台场景，字重克制会导致层级丢失。"
```

## 使用方式

管线第 3 步执行时，若本目录对应媒介下已有案例，Read 后作为判断标杆对齐——**学习其决策逻辑，禁止像素级模仿**。标杆的意义是校准"什么叫好"，不是提供新模板。

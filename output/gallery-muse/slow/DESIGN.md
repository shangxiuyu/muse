# 山野之间，自在呼吸

由项目 Muse 6.0 创作引擎实际生成，模型标识：deepseek-v4-flash。

## 作品契约与设计判断

**概念（Muse 原创概念样板；品牌、器物、工坊与采集记录均为虚构示例）**

旧版把「山野之间」做成了通用生活品牌 hero + 三等分卡片，植物标本只是右侧一张装饰图，编号、采集信息与内容之间没有关系。这次重做的是**组织方式**，不是配色。

- **Content DNA**：主角是「可辨认的标本与器物的实物档案」；处境是城市人在夜里或周末的间隙想减速；核心关系是 标本 → 采集地与季节 → 材质手感 → 它给日常带来的时间感。**张力：标本的精准（编号、采集日、学名、坐标）与生活的松弛必须同时成立**。
- **结构假设**：让「档案编号」成为全站骨架。品牌故事、自然历、器物档案共享同一套 NO. 01–06 采集档案格式，阅读路径是「野外 → 器物 → 家里」。
- **辨识关系**：① 标本纸随**晨 / 午 / 暮**切换，叶色、纸色、光晕、栏线、图注与左侧文案同步改写；② 每件器物是可原位展开的档案盒，展开在原位置推挤，不弹窗、不跳页。
- **克制规则**：只有一抹苔绿做强调，无琥珀、无大阴影、无渐变；层级靠 1px 栏线而非容器承担。

**Dials**：VARIANCE 6（首屏 5:7 非对称分屏、自然历错位缩进、卡片第二列下沉；移动端强制单列）／ MOTION 4（缓出曲线，仅状态跃迁）／ DENSITY 3（画廊式呼吸）。
**母体**：Writer's Atelier —— 暖燕麦纸底 + 纸白卡片 + 1px 出版栏线 + 宋体长文（≥15px）+ 无衬线微文案。**有意偏离该母体的琥珀强调色**：客体是苔与纸，强调色改为苔绿 #4A6142；暖琥珀只保留在标本纸的光晕里，不参与 UI 焦点。

**内容结构**：① 首屏（非对称分屏 + 时刻切换）② 品牌故事（左窄右宽，硬数据裸排不装卡片）③ 自然历（错位缩进的田野记录，标出当季）④ 器物档案（三张可展开档案盒，中列下沉）⑤ 季候信（含校验、禁用、成功回落）⑥ 页脚（概念示例明示）。

**标本图的六轮迭代记录（这是本样板最容易出错的地方）**：① 叶过大挤满画框 → ② 用 `rotate()` + `scale(-1,1)` 推导叶形，镜像侧叶片塌到主轴上融成一根实心棍 → ③ 改绝对坐标显式路径，但整株过大、底部叶被切断 → ④ 加 0.84 等比缩放，枝形正确但顶部左叶压住「木犀科」学名标签行 → ⑤**本稿**：改为 `translate(52 34) scale(0.78)`，整株下移 40px 且略收，使枝梢芽点、七片叶尖、主枝下端全部落在版心栏线内，且与上方学名标签、下方采集地标签、右下比例尺三处均无重叠。

**交互与状态**：时刻切换（aria-pressed）· 档案原位展开（aria-expanded，重播推挤动画）· 季节筛选（空状态为行动邀请、可回到当季并把焦点送到当季标题）· 订阅（错误把光标送回输入框、可一键填入示例邮箱、禁用态、成功后留出换邮箱入口）· 键盘全链路可达、focus-visible 高反差环、跳转主内容、移动端 44px 靶区、prefers-reduced-motion 全量降级。

**自检与未验证边界**：已核对 JS 语法（IIFE、无外部依赖、无 localStorage、无第三方库）、HTML/CSS/JS 三文件分离、无网络字体与图片链接；已按桌面截图连续六轮检查并修正首屏标本图。**尚未**在真机 390 宽度与 1440 全页实测，**未验证**响应式重排、筛选与订阅的完整交互路径、200% 文字缩放；仅经静态检查与桌面首屏截图，未跑浏览器自动化。不宣称输出 PPTX。品牌、器物、工坊与采集记录均为虚构示例，不含真实客户、成绩或背书。

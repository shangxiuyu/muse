# 场间，设计正在发生

由项目 Muse 6.0 创作引擎实际生成，模型标识：deepseek-v4-flash。

## 作品契约与设计判断

【概念示例声明】「场间 FIELD NOTES 设计艺术周」及全部 6 场活动、讲者、展位区均为明确标注的虚构内容，非真实活动或主办方；顶部状态条、须知区与页脚三处均可读到该声明。

PASS 1 · 情境与关系推导
受众是想安排一天看展的设计爱好者，多在夜里排程、手机粗看、桌面细排。内容客体是展览现场的物质性：坐标纸、展签、平面图、编号、铅字。色板即由此提炼——朱红 #C2321F（约 8% 面积，只用于场次序号、选中态、冲突边框与「间」字）、墨黑 #1A1714、暖白纸底 #F5F1E9、暖灰结构线 #CFC5B2。24px 坐标网格与极淡纸纹给暖白重量，避免纸白显得廉价。

版式不由母体决定：以「展场平面图」为骨架——左栏是图例（筛选即图例项），中栏是展位带（每场一行横向坐标块，序号是全页最大等宽字号），右栏是检视面板（观展单）。刻意不做居中 Hero、不做横排三等分卡片、不做全圆角玻璃盒。母体（Neo-Brutalist Engineering）只贡献表层：2px 炭墨硬线、2px 微圆角、7px 位移按钮、等宽技术标签。中文标题用正字距 + 无衬线承载「大写感」，等宽只用于短标签与数字。

PASS 2 · 对抗平庸与克制
- 首屏第 1 秒锚点只有「场间」两个大字与其下日程入口，其余全部退让；平面图与三日条是第二、三层，不与之竞争。
- 香奈儿精简：删掉初稿的卡片悬浮抬升、装饰性徽章与发光球，只保留每行一个序号。
- 创新：微创新 M2 状态流变（「加入观展单」原位变为「✓ 已加入」再收拢，全程无弹窗）+ M4 语义联动（加入时右侧观展单对应条目呼吸微光一次，移动端坞同步闪一次回执）。深度范式 D4：介绍与讲者备注全部原位推挤展开（grid-template-rows 0fr→1fr），不用 Modal；D2 熔接：暖白纸页中嵌入墨黑展签式分区条。

PASS 2 · 主动声明
css 顶部以 muse:allow 显式声明两处偏离并附理由：2px 硬边框（本作品的形式语言：图纸描边与分区边框）、Grain 纸纹（fixed inset-0 pointer-events-none 独立层，isolation:isolate、z-index:1，压在内容下，不参与滚动重绘）。

另有一处需要明说的取舍：三日条是三格等宽。默认规则封杀横排三等分卡片，但这里是时间标尺而非卡片组——三格各自承载不同的场次数与起始时间（2 场 13:30 起 / 3 场 10:00 起 / 1 场 11:00 起），读作刻度条。若后续内容变成三张并列资讯卡，需改回非等宽。

两轮修正记录
- 第一轮截图暴露真实缺陷：移动端底部观展单坞在桌面宽度下仍显示并遮住三日条下沿。原因是 `.dock{display:flex}` 的优先级压过 `hidden` 属性。已补全局 `[hidden]{display:none !important}` 与 `@media (min-width:821px){.dock{display:none}}` 双重保险。
- 同时收紧 hero 纵向节奏（标题 clamp 上界 208→176px，首屏上内距 56→40px），使 1200×750 缩览能同时看到主题、平面图与三日条。
- 第二轮截图确认：坞已消失，三日条完整可见，无横向溢出，首屏三个层次清晰。

交付与检查范围
- 实现：日期/类别双组筛选（真实 button + aria-pressed，键盘可操作）、原位展开介绍与讲者备注、加入/移除观展单、计数三处同步、时间冲突提醒（同日时段重叠才报，不阻止加入）、三日总占用时长、空状态三件套（意境 + 行动按钮 + 可载入示例）、筛选无结果状态、:focus-visible 焦点环、prefers-reduced-motion 降级。
- 全部可点击元素 min-height ≥ 44px；正文 15–16px，标签 12–13px；未使用 localStorage；无外部网络依赖、图片链接或字体 CDN。
- 已实测：在浏览器实际渲染中观察两轮截图，确认顶栏、首屏三层结构、平面图与三日条可见且不溢出；逐行核对 JS 语法与括号配对。「筛选 → 展开 → 加入 → 冲突提醒 → 移除 → 清空 → 载入示例」路径已按代码逻辑核对，但仅截图可证明首屏渲染。

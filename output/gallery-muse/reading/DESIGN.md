# 拾页，把时间还给阅读

由项目 Muse 6.0 创作引擎实际生成，模型标识：deepseek-v4-flash。

## 作品契约与设计判断

【概念】「拾页」是夜间阅读工作台，非营销页。品牌与 4 本书均为虚构概念示例（《慢的证词》《深夜的十六条街》《雨的编年史》《纸与它的时代》），无真实作者、无销量评分背书。

【情境与视觉关系】受众在碎片信息之后、用半小时认真读一会儿。第 1 秒锚点是右侧大幅书封与中央书页——全屏唯一亮面；深墨蓝骨架退让，暖纸白与墨色正文承担阅读。冷（墨蓝）×暖（纸白／杏色）为核心张力，杏色只落在计时运行态、当前书与首字下沉，面积 <8%。书封为纯 CSS 排印 + SVG 几何（弧线／网格／雨线／叠页四母题），无图片。

【结构】三段式：紧凑侧栏（导航＋我的书架，搜索与在读/想读/已读筛选）— 中央在读书页（书封信息、章节、正文、本次札记）— 右栏书封与计时。移动端单列，计时收进底部操作坞。

【主要交互】搜索（含命中高亮）、状态筛选、选书切换、开始/暂停/重置计时（每本书独立计时）、札记可编辑。数据仅存内存，不使用 localStorage。空状态给行动邀请，错误给修复路径。

【三轮修正记录】一轮：大书封只有几何底层、排印层漏写样式，补齐整套书封版式。二轮：侧栏书脊竖排中文被 max-height 截断成残字，改为每本书取两字短标（慢的／深夜／雨的／纸与），并收窄右栏使书封与计时同屏。三轮：书封图注换行成两行破坏右栏秩序，缩短为单行。

【有意偏离并声明】默认浅底范式反转为深墨蓝基底：夜间长时阅读，大面积发光底板致疲劳；「纸面浮在墨底上」是作家案头母体材质隐喻的倒置，属形式语言。声明见 CSS 顶部 muse:allow。对比度、触控靶区、事实标注未豁免。

【检查边界】已核对三轮桌面截图的内容完整性、溢出、书封排印与断行。未验证：真实浏览器下的移动端手势与全篇交互路径、计时长时间会话表现、200% 文字缩放。计时、筛选、选书、札记保存等交互只做了源码推演与语法自检，未在截图中观察到运行结果，不宣称已通过交互测试。

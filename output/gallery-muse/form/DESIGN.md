# FORM，给想法以形状

由项目 Muse 6.0 创作引擎实际生成，模型标识：deepseek-v4-flash。

## 作品契约与设计判断

概念：独立工作室 FORM 的作品集，用国际主义排印的严格网格 + 克制的单一钴蓝，把「先问为什么，再决定长什么样」变成可浏览的证据链。情境：品牌主理人先在明亮办公室快速扫视、再决定要不要联系；移动端是通勤中的手机预览，因此信息顺序按「主张 → 证据 → 报价 → 联系」排列，不依赖悬停。结构重组（非改标题）：① 首屏左对齐巨型标题 + 右侧三段事实（成立年份 / 方向 / 产能），不用居中 Hero；② 项目区改为 7:5 非对称双列 + 编号索引，替代旧版四张等高卡；③ 筛选从四个等宽按钮改为标准 tablist，支持 ← → Home End 键位，并新增空状态与数量播报；④ 服务从一行三词改成 01/02/03 编辑式报价表 + 原位展开（D4），说明交付物与周期；⑤ 新增完整联系表单，含 label 绑定、错误提示、焦点回位与重置态，让样板在其虚构业务下真正可用。取舍：删掉旧版鲑鱼橙/鼠尾草绿/墨绿多色调色板——四色互相抢戏且违反「单一强调色 + 全局色温统一」，改为钴蓝 60 / 骨白 30 / 洋红 ≤10 的三层关系，洋红只落在眉题、编号与激活指示；省掉一切装饰渐变与发光，把锋芒留给巨型标题与网格本身。创新：M4 跨区语义联动（悬停或聚焦项目 → 服务表对应行亮起，鼠标与键盘都触发）；D4 原位推挤展开替代弹窗。前两轮修正：① 7:5 双列此前靠 aspect-ratio 自然撑高，左宽卡与右侧叠卡底边不齐，改为桌面端网格两行等高 + 面板 flex:1，宽卡跨两行后必然与右列齐底，窄屏撤回单列与 4:3 定比；② 提高次级灰对骨白的对比度、把洋红从 #C4007A 下调到 #B00070，保证小字达标。有意偏离：使用近黑墨色 #0B0F1A 与洋红强调，属本母体（线框架构师 / 瑞士排印）形式语言，已在文件内以 muse:allow 声明。验收：在 1200×750 缩览下实际观察首屏与项目区起始渲染，标题层级、7:5 分栏边线、tab 选中态与洋红面积符合预期；JS 已逐行核对语法与所有 getElementById / dataset / 事件绑定目标，均存在。未验证：本环境截图固定于页面顶部，项目卡下半部、服务原位展开、表单错误与重置态、以及 390 窄屏均未在本次观察中看到，不能声称已通过；未做真机触屏测量 44px 靶心、未做屏幕阅读器朗读、未做 200% 文字缩放。所有品牌、项目、报价与联系地址均为概念示例，已在页脚明示。

## 📖 核心哲学：美是关系的艺术 (Aesthetics as Relations)

当今大多数 AI 生成的内容（无论是 UI 界面、长文、PPT 还是图片）之所以充斥着强烈的**“AI 塑料感”与同质化平庸（AI Slop）**，是因为传统模型仅在做孤立符号的统计学拼凑：千篇一律的紫色渐变、毫无节制的大圆角、空洞卡片堆叠、假大空的公文排比句，以及缺乏真实重力与物理质感的浮尘光斑。

**Muse 确立的全局第一性原理：美不是规则，而是关系的艺术。**
- **孤立元素无所谓美丑**：色彩、间距、字体、动效单独存在时没有优劣；只有当它们与**具体情境（Context）**、**受众心智（Audience）**和**深层内容（Content DNA）**达成恰当共振时，美才会发生。
- **判断先于生成**：在敲下第一行代码、落笔第一段文字前，必须先完成情境解构，确立坚不可摧的**设计契约（Contract First）**。
- **跨端同构，自适应推断**：拒绝把移动端降级为粗劣的“缩小版网页”；美学母体是唯一真实源，由设计系统深层语言自主推导全端交互形态。

## ⚡ 四大媒介全景赋能与契约体系 (Cross-Media & Contracts)

Muse 不仅关注 UI，更将审美推理贯穿至现代数字创造的四大核心媒介。**“落笔先立契”**，杜绝未定方向盲目生成：

### 1. 💻 UI / UX 界面设计与交互前端
- **契约先行**：强制在项目根目录交付 [`DESIGN.md`](references/toolkit/ui_adapter.md)，锁定业务目标、母体流派、设计令牌、组件 7 态契约与响应式断点。
- **Bento 2.0 活体组件库**：彻底抛弃死板卡片，引入时间轴心跳卡、高亮数据压舱卡、微动效雷达卡等动态活体原型。
- **微交互兵器库**：非对称布局、流体磁性吸附、微光边框扫射、键盘无障碍焦点环。
- **入口手册**：[UI 媒介适配器](references/toolkit/ui_adapter.md) · [UI/UX 全能实战手册](references/toolkit/ui_product_tool.md) · [美学文法](references/toolkit/ui_grammar.md) · [视线心流与交互](references/toolkit/ui_interaction_flow.md)

### 2. ✍️ 文本深度叙事与行文质感
- **契约先行**：先输出 [`WRITING.md`](WRITING.md)，明确受众心智、叙事动线、文风基调、句法音律与客观事实账本。
- **四大深层架构**：侦探剥茧式（打破常识）、思想拼图式（模块拼合）、现场特写式（微观推演）、辩证对冲式。
- **24 种微创去油手术**：全面粉碎 AI 腔调（“在这个快速发展的时代”、“总而言之”、“不可否认”等套话彻底清除）。
- **入口手册**：[文本内容生成实战手册](references/toolkit/text_narrative_tool.md) · [文本质量复核与去油](references/toolkit/text_quality_protocol.md) · [作者声音画像](references/personal_assets/author_voice_profile.md)

### 3. 📊 演示文稿与现场演说 (Web Deck)
- **契约先行**：先确立 `PPT.md` 演说契约，锁定主讲场景探针、屏人二重奏账本（投影幕只放证据与情绪，台词全在演讲者嘴里）。
- **Theme Rhythm 呼吸节律**：严格遵循明暗冷暖交替节奏（Light Setup 铺垫 → Dark Focus 顿悟点题 → Split Proof 深度论证）。
- **单文件 Web Deck 交付**：使用标准 HTML+CSS 交付原生可全屏演示、带快捷键与动效的现代 Deck，拒绝排版错乱的 PPT 转换。
- **入口手册**：[演示文稿与演说实战手册](references/toolkit/presentation_tool.md) · [演示美学母体](references/toolkit/presentation/archetypes.md) · [相遇与淘汰原则](references/toolkit/presentation/encounter_and_rejection.md)

### 4. 🎨 概念视觉生图与艺术指导
- **契约先行**：集中管理全部图片资产的 [`IMAGE.md`](IMAGE.md)，建立逐图意象账本与留白安全区。
- **物理真实法则**：拒绝无理由漂浮，必须具备物理落地重力、单一物理主光源（色温自洽）、未涂布纤维或拉丝金属微质感。
- **结构化 Prompt 输出**：针对 Midjourney / Flux / SD 输出“主体 + 构图画幅 + 物理光照 + 胶片材质 + 负向排除”全量提示词。
- **入口手册**：[图像生成实战手册](references/toolkit/image_visual_tool.md) · [专业摄影理论与布光](references/toolkit/photography_tool.md) · [视觉语法](references/visual_grammar.md)

## 🚀 极速上手 (Quick Start)

### 1. 安装方式

#### 方式 A：在 Antigravity IDE 中使用（推荐）
直接将 `muse` 文件夹置于工作区项目的 `.agents/skills/muse/` 或全局 `~/.gemini/antigravity-ide/builtin/skills/`，智能体将自动发现并无缝激活。

#### 方式 B：在 Claude Code / Claude Desktop 中使用
将本仓库克隆至你的 Agent Skills 目录：
```bash
git clone https://github.com/shangxiuyu/muse.git ~/.claude/skills/muse
```

#### 方式 C：在 Cursor / Windsurf 中使用
在项目根目录 `.cursorrules` 或 `.windsurfrules` 中添加引用：
```markdown
遵循 Muse 审美规范 (参考 skills/muse/SKILL.md)。开发前必须先输出 DESIGN.md/WRITING.md 契约。
```

### 2. 常用自然语言 Prompt 示例

- **立项全新 UI**：
  > “我想做一款注重安静心流的 Markdown 笔记应用，请调用 Muse，锚定最契合的美学母体，先为我输出一份工业级 `DESIGN.md` 设计契约。”
- **深度写作与去 AI 味**：
  > “帮我撰写一篇关于《大模型时代的个人开发者出路》的随笔，先在 `WRITING.md` 中拆解受众心智与侦探式架构，彻底去除 AI 腔调。”
- **打造高端演说 Deck**：
  > “我们需要向投资人汇报新产品，请用 Muse 的‘屏人二重奏’法则和 Theme Rhythm 节奏，交付一份单文件 HTML 演示文稿。”
- **提取个人审美品味**：
  > “分析这个网站（或这段排版），提取它的深层美学系统和适用边界，收录到我的 Taste Vault 记忆库中。”

### 5.1.0：UI 回到媒介适配器与精细化分治
- 拆掉「全能作战手册」。UI 默认只读 [适配器](references/toolkit/ui_adapter.md)：路由、顺序、契约字段。
- `DESIGN.md` 锁任务、假设、系统、结构、对象、运动与验收，不再锁皮肤、旋钮和自评打分。
- 施工百科升级为 [美学文法](references/toolkit/ui_grammar.md)、[视线心流](references/toolkit/ui_interaction_flow.md)、[底线](references/toolkit/ui_floors.md) 与 [范式示范](references/toolkit/ui_creative_arsenal.md)。
- 界面决策以 [DESIGN.md 契约](references/toolkit/ui_adapter.md) 落地，不锁死单一 CSS 框架。

### 5.0.0：美是关系的艺术与 UI/UX 工业级重构
- **确立全局最高哲学：美是关系的艺术**。六大元原则统领全媒介（UI/UX、文章、演示、图像）。
- **UI/UX 体系脱水重构（道 · 法 · 体 · 术 · 器）**：构建从顶层哲学到生产级代码交付的现代工业级防线。
- **模式分流与量化杠杆**：确立 Expressive、Convention、Existing 三模式分流；引入审美三旋钮。
- **六大维度工程化深化**：排版布局反默认居中、从具体客体推导 4–6 色具名调色板、角色化字体配对、GPU 动效性能铁律。
- **Anti-Slop 十大工程军规**：禁用 Emoji、严禁 Lila 紫蓝发光渐变、严禁破坏键盘焦点环、严禁灰底灰字低对比。
- **标准交付契约**：写代码前先立契约，在项目根目录交付标准 `DESIGN.md`。

### 4.9.0：让 Muse 回到审美导演
- 将演示定义为观众在时间中连续经历的感知相遇，区分 speaker-led、reader-led 与 hybrid。
- 建立整套运动与十一类页面职责；先记录状态、主张、证据、意图，再决定版式。
- 新增 Presentation DNA 与整套验收闭环。

### 4.7.0：让 UI 方向可以安全延续与比较
- 新增 UI 目标路由：区分已有界面、新目标和空白项目。
- 新增 direct edit／replace／branch 决策与 UI 资产协议。

### 4.6.0：把审美训练转成可执行视觉语法
- 视觉语法：第一眼主角、阅读路径、潜在网格、受控破格、层级、留白与构图。
- 摄影方法：曝光三角、十六类构图、九种光位、六类摄影关系。

### 4.5.0：从风格识别走向案例式系统推理
- 案例式审美训练：按表面、机制、系统、关系、情境五层阅读品牌与流行风格。
- 引入去标签、换表面、换情境和系统一致性四个反事实测试。

### 4.4.0：从记录感受走向可追溯学习
- 打通“真实反应 → 可迁移推断”的正式证据链。

### 4.2.0：从内容 DNA 到自身形式

- 反同质化从换色检查扩展到归因测试与反事实替换。

### 4.1.0：从“定义美”到“美如何发生”

### 4.0.0：审美智能与品味记忆双引擎确立
